CH 01 Chrome 拡張機能 を install する 初回 10分

Zoom 面談 の 音声 を 自動 録音 する ため、 専用 Chrome 拡張機能 を install する。 Chrome Web Store 未公開 の ため zip を DL → 手動 install (unpacked mode)。

1拡張機能 zip を DL

下 の button で zip DL (13KB)。 Downloads に FP-Compass-拡張機能.zip が 落ちる。

📥 zip を DL

2zip を 展開 して 好きな場所 に 置く

Downloads の zip を ダブルクリック → FP-Compass-拡張機能 フォルダ が できる。 Documents や Desktop に 移動 して 消さない ように する。

⚠ フォルダ を 消さない: unpacked mode の 拡張 は フォルダ を 指す。 消したり 移動したり すると 拡張 が 使えなく なる。
3Chrome で chrome://extensions/ を 開く

Chrome の URL バー に chrome://extensions/ を 貼り付け → Enter。 (または Chrome 右上 の … → 「拡張機能」 → 「拡張機能 を 管理」)

4「デベロッパー モード」 ON → 「パッケージ化 されていない 拡張機能 を 読み込む」

ページ 右上 の 「デベロッパー モード」 switch を ON。 左上 に 3 つ の button が 出る → 「パッケージ化 されていない 拡張機能 を 読み込む」 を click。

ファイル 選択 ダイアログ → 手順 2 で 展開 した FP-Compass-拡張機能 フォルダ を 選択 → 「開く」。

5install 確認 + pin

拡張機能 の カード が 出て、 version が 1.2.0 なら 完了。

Chrome 右上 の 拡張 アイコン (🧩) を click → 「FP Compass 議事録レコーダー」 の 隣 の 画鋲マーク を click で pin 固定 して おく と 便利 (常時 表示)。

CH 02 FP Compass に login 30秒
1https://app.skeleton-inc.jp/ を 開く

Chrome で https://app.skeleton-inc.jp/ を 開くと login 画面 が 出る。

▲ login 画面 — メール + パスワード
2メール と パスワード で login

登録済み の メール と パスワード を 入れて 「ログイン」。 30日間 login 維持。

login 後、 dashboard (ホーム) が 出る。 左 サイドバー に 「顧客台帳」 「面談履歴」 「LINE オートメーション」 等 の nav。

▲ login 後 の dashboard (ホーム)
CH 03 Zoom 面談 を 開始 (1 click で 自動録音) 1 click
1左 サイドバー の 「顧客」 タブ を click

login 後、 左 サイドバー の 「顧客」 nav を click → 顧客台帳 が 出る。

▲ 顧客台帳 (客一覧 table)
2面談したい 客 を click → 顧客カルテ が 開く

table の 客 の 行 を click → 右側 に 顧客カルテ が 開く。 上部 に 客名 + status、 その 下 に アクション button 群。

▲ 顧客カルテ — 上部 に アクション button, 下 に 詳細
3「⚡ 今すぐ 開始」 button を 1回 click

顧客カルテ の 中 に 青枠 の Zoom アイコン button が 2つ 並んで いる:

  • ⚡ 今すぐ 開始 ← これ を 押す
  • 📅 日時指定 予約 (後日 の 面談 予約用)
▲ 顧客カルテ の Zoom button 2つ (左 = 今すぐ / 右 = 予約)
💡 LINE 紐付け 有無 で sub label が 変わる: LINE 有り → 「LINE 自動送付」、 無し → 「URL コピー可」。 どちら でも 拡張 の 自動録音 は 動く。
4拡張 が 自動 で 動く

button click 後、 owner は 何 も しない。 裏で こう 動く:

  1. 拡張 が この 客 で 「録音準備完了」 に なる (右上 HUD に 🟡 表示)
  2. Zoom タブ が 新規 open
  3. Zoom タブ の 読み込み 完了 → 自動 で 録音開始 (HUD が 🔴 に 変わる)
⚠ 「自動起動 失敗」 と 出た 場合: Chrome の セキュリティ で 自動 tabCapture 失敗 する ケース あり。 その 時 は Zoom タブ に 切り替えて Chrome 右上 の 拡張 アイコン (▶ 緑 badge) を 1 click で 録音 開始。
5Zoom で 面談 (AirPods OK)

普通 に Zoom で 面談する。 AirPods 使用中 でも 相手 の 声 と owner の 声 両方 録音される:

  • 相手 の 声: Zoom タブ の 音声 を 拡張 が 拾う (AirPods 経由 で 聞こえてる 音声)
  • owner の 声: マイク (AirPods) を 拡張 が 拾う
6面談 終了 → Zoom タブ を 閉じる だけ

Zoom タブ を × で 閉じる だけ。 拡張 が 検知 → 自動 stop → 音声 blob を FP Compass に 送信 → Whisper で 文字起こし → Claude で 5 section 議事録 生成 → 顧客カルテ の 議事録タブ に 表示 (5〜10分)。

ℹ 停止 button 押す 必要 なし: Zoom タブ 閉じた 瞬間 に 自動 stop + 送信 + 生成 まで 全部やる。
CH 04 画面 右上 の 状態パネル (HUD) — 今 何 が 起きてる か 常時 表示

FP Compass 画面 右上 に 小さい パネル が 出る。 「今 拡張機能 が 何 を してる か」 が 全 段階 で 分かる。

🟡 録音準備完了
Zoom button click 直後 に 出る。 拡張 が 客名 を 記憶 して、 Zoom タブ の open + 録音 開始 を 試みる 段階。
WHEN — Zoom button click 直後
🔴 録音中
Zoom タブ の 音声 + マイク (AirPods) を 収録中。 Zoom タブ を 閉じる まで 継続。 この間 は 何 も しない。
WHEN — Zoom タブ load 完了 → 自動 開始
⚠ 自動起動 失敗
Chrome の セキュリティ で 自動 tabCapture 失敗。 Zoom タブ に 切り替えて Chrome 右上 の 拡張アイコン (▶ 緑) を 1回 click で 録音開始 する。 (完全自動 の 半歩手前)
WHEN — auto-start が Chrome policy で 失敗した時
⏳ 議事録 生成中…
Zoom タブ 閉じた 直後 に 出る。 「音声 XX KB, YY秒 受信」 の 数字 で 「ちゃんと録れてる」 が 確認できる。 5〜10分 待つ と 完成。
WHEN — Zoom タブ 閉じた 直後
✅ 議事録できました
5〜10分 経過 して 議事録 が 完成 した 通知。 「顧客カルテで開く」 button を click で 該当 客 の 議事録タブ に 直行。
WHEN — 議事録 fetch 完了 (5-10分後)
ℹ HUD の 操作: 右上 × で 手動 閉じ 可能。 sticky でない state は 15秒 で auto-hide。 面談中 も 邪魔 に なりにくい 位置。
CH 05 議事録 を 確認する 面談 5-10分後
1顧客カルテ の 「議事録」 タブ を 開く

該当 客 の 顧客カルテ を 開く → 上部 の タブ で 「議事録」 を 選択。 過去 の 議事録 が 時系列 で 並ぶ。

▲ 顧客カルテ → 議事録タブ
2議事録 の 構成

各 議事録 は 以下 5 セクション に 自動 分解 されて 表示 される (2026-07-17 以降 の 新規 面談):

  1. 本日の決定事項 (緑 pill) — 面談で 決まった こと
  2. お客様の関心事 (indigo pill) — 顧客 の 現状 / 希望 / 家族構成
  3. 次回までのTODO (橙 pill) — FP先生 が 次回まで に やる こと
  4. 懸念事項 (赤 pill) — リスク / 不確定要素
  5. 議論した数字・試算 (黒 pill) — 出た 数字 の 集約

数字 と 大事な語句 は 黄色 蛍光ペン で 目立つ。 詳細 デザイン は meeting-single.html で 確認 可能。

CH 06 うまく 行かない 時 トラブル 対処
?顧客カルテ に Zoom button が 見えない

症状: 顧客カルテ を 開いても 「⚡ 今すぐ 開始」 button が 表示 されない。

原因: 旧 版 では LINE 紐付け 済 客 のみ 表示 だった。 2026-07-18 修正 で 全客 で 表示 に。

対処: FP Compass を Cmd+Shift+R (ハードリロード) → 新 UI が 反映される。

?「自動起動 失敗」 の HUD が 出た

症状: HUD 右上 に ⚠ 橙 の 「自動起動 失敗」 表示。

原因: Chrome の セキュリティ で 自動 tabCapture が blocked。

対処: Zoom タブ に 切り替えて Chrome 右上 の 拡張 アイコン (▶ 緑 badge) を 1回 click → 録音 開始 (半自動)。

?拡張機能 が 認識 されない

症状: Zoom button 押しても HUD が 出ない、 何 も 起きない。

対処:

  • Chrome の chrome://extensions/ で 「FP Compass 議事録レコーダー」 が v1.2.0 か 確認
  • switch が ON か 確認
  • FP Compass タブ を Cmd+Shift+R でハードリロード
  • DevTools (F12) console で window.__fpTabRecorder と 打って "1.2.0" が 返る か 確認
?マイク (自分の声) が 入らない

症状: 議事録 で 相手 の 声 だけ、 自分の 声 が 入って ない。

対処:

  • Mac の システム設定 → プライバシー と セキュリティ → マイク で Chrome が ON か 確認
  • Chrome の URL バー 左 の 🔒 → 「サイト の 設定」 → マイク が 「許可」 か 確認
  • AirPods 使用時 は Mac の 「サウンド → 入力」 で AirPods が 選択 されて いる か 確認
?議事録 が いつまでも 出ない

症状: HUD が 「⏳ 議事録 生成中」 の まま 30分 以上 経つ。

対処:

  • FP Compass タブ を リロード → 議事録 が 出て いる か 確認
  • 顧客カルテ → 議事録タブ で 「AI処理失敗」 表示 が 出て いない か 確認
  • 継続 で 失敗 する 場合 は 音声 の 品質 (無音 / 音量 小さすぎ) を 確認

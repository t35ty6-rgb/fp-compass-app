Part B / 3

マイク設定 ウィザード3 分

AirPods や 内蔵mic を 拡張 に 覚え させます。 これ を 通さない と AirPods で 自分の声 が 録れません。

v1.5.1 で 新設

3 ステップ の ウィザード で 完了

マイク許可 → デバイス選択 (AirPods 明示) → 5秒 テスト録音 の 3 ステップ。 これ を 通す と 以降 の Zoom 面談 で 拡張 が 自動 で AirPods の マイクモード を 呼び出します。

前提: AirPods を Mac に 先 に Bluetooth 接続 して おく。 メニューバー の Bluetooth アイコン で 「接続済」 確認。

1

拡張 の アイコン から ウィザード を 開く

Chrome 右上 の 拡張機能 アイコン (パズル 型) → 「FP Compass 議事録 レコーダー」 を クリック → ポップアップ が 出る。

ポップアップ 下部 の 黄色 バナー 内 の 「マイク設定 を 開く」 リンク を 押すと、 新しい タブ で ウィザード が 開きます。

拡張 アイコン を 右クリック → 「オプション」 でも 同じ ウィザード に 到達 可能 (Chrome の バージョン に 依存)。

2

Part C / 3

Zoom で テスト録音4 分

実際 の Zoom 面談 と 同じ 手順 で、 テスト 用 の ミーティング を 使って 議事録 に 自分の声 が 入る か 確認 します。

1

FP Compass で テスト顧客 を 開いて 「録音準備」

FP Compass に ログイン → 適当 な テスト用 顧客カルテ を 開く → 「急遽 面談スタート」 → 「Zoom を 発行 して 開始」 を 押す。

✓
Chrome 右上 の 拡張 アイコン に 緑 ▶ が 光ったら 「録音準備 済み」 の 合図。
2

Zoom タブ で 拡張 アイコン を クリック → 「録音 を 開始」

新しく 開いた Zoom タブ で ブラウザ 版 で 参加 (Desktop アプリ が 立ち上がっても、 Zoom の 「ブラウザ から 参加」 リンク を 押して ブラウザ で 開き 直す)。

Zoom タブ を 前面 に して 拡張 アイコン を クリック → ポップアップ の 「録音 を 開始」 ボタン を 押す。

✓
拡張 バッジ が 「REC」 (赤) に 変われば 録音 中。
Zoom は ブラウザ 版 で 開いて ください (Desktop アプリ で 参加 すると 拡張 は タブ 音声 を 拾えず、 議事録 が 無音 に なります)。
3

10 秒 話して 停止 → 議事録 確認

AirPods 付けた まま 「あー、 テスト 録音 です」 を 10 秒 話す → 拡張 ポップアップ の 「■ 録音 を 停止」。

FP Compass の 顧客カルテ に 戻る → 「議事録」 タブ を 開く → 5〜10 分 待つ (AI 文字起こし 処理 中) → 議事録 が 追加 される。

✓
議事録 の audio player で 自分の声 が 聞こえれば 完全成功。 これで 実際 の 面談 で 使えます。
Part D / 3

よくある 質問

議事録 に 自分の声 が 入って いない

Part B の ウィザード を 通して いない 可能性 が 高いです。 拡張 ポップアップ の 黄色 バナー を 確認 → 「マイク設定 を 開く」 で ウィザード を 通して ください。 それでも ダメ なら 診断ガイド を 参照。

Console に [auto-start] failed と 赤い エラー が 出る

これ は Chrome の 仕様 で バグ で は ありません。 拡張 は 自動 で 録音 を 始めた がった が Chrome の セキュリティ で 弾かれた、 だから 「あなた が 拡張 アイコン を 押して ね」 の 意味。 Zoom タブ で 拡張 アイコン を 1 回 押せば 録音 開始 します。

AirPods 使うと やっぱり 声 が 入らない

Part B の STEP 3 の レベルメーター が 動いた か が 分かれ目。 動かない 場合 は macOS の HFP プロファイル 切替 が 発火 していません。 対処 → AirPods を 外して 再装着 → Mac の 「システム設定 → サウンド → 入力」 で AirPods 手動選択 → ウィザード STEP 3 を もう 一度。

Zoom タブ を 開いたら Desktop アプリ が 立ち上がる

Zoom の ダウンロード ページ に 「ブラウザ から 参加」 の 小さい リンク が あります。 それ を 押す と ブラウザ 内 で Zoom が 開きます。 これ で ない と 拡張 は 音声 を 拾えません。

複数 の Chrome プロファイル を 使って いる

拡張 は インストール した プロファイル でしか 動きません。 Chrome 右上 の プロファイル アイコン で、 拡張 を 入れた プロファイル に 切り替えて ください。

会社支給 Mac で 管理者 権限 が ない

Part A の 「デベロッパー モード」 と 「読み込み」 は 管理者 権限 なくても 動く 場合 が 多い です。 ダメ なら 情シス に 「Chrome 拡張 の 開発者 モード を 使いたい」 と 依頼 して ください。

これ でも 直らない 時 は

サポート メール → support@skeleton-inc.jp
その 時 に Chrome の バージョン (アドレスバー に chrome://version を 貼って 最初の1行 を コピー) と macOS の バージョン ( アップルメニュー → 「この Mac について」) を 添えて 頂けると 早く 特定 できます。

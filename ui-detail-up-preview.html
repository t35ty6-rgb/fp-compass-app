FP COMPASS · 段階 改善 (現行 UI を base に detail up)

今 の FP Compass の 5 個所 を detail-up する 案

現行 の UI 構造 は 維持、 「見た目 と 押しやすさ の 細部」 だけ を 5 個所 改善 する 案。 大幅 な 書き直し なし、 CSS + 一部 HTML 差替 で 実現 可。 全 案 とも 40-60代 の 「文字 小さい / どこ 押す か 分からない」 を 解消 する 方向。

CASE 01

左サイドバー 拡大 + 主 CTA 「面談 を 開始」 明確化

対象: styles-v8-workspace.css .cd-left

顧客カルテ の 左 プロフィール が ぎっしり 詰まって いて 押す べき 場所 が 迷子。 アバター と 名前 を 一回り 大きく、 「面談 を 開始」 を 目立つ 大 primary button (52px 高) に。 タグ / アンケート 等 の 副次 button は 下 に 従属。

  • 「面談 を 開始」 button 8px → 14px padding · 15px 太字 · 動線 説明文 付与

タブ バー (概観/LINE/議事録/…) の 視認性 向上

対象: .cd-tabs, .cd-tab

現状 7 タブ (概観 · LINE · ライフ · 議事録 · Q&A · 家族 · 更新) が 詰まって 12px 相当、 アクティブ が どれ か 一目 で 分から ない。 タブ を 16px + 20px padding に 拡大、 アクティブ の 下線 を 3px 太字 で 明示、 「0」 バッジ は 非表示 (数字 が ある タブ だけ 出す)。

  • タイトル に 動詞 追加 (「初回接触」 → 「初回接触 の メッセージ を 送る」)
  • 「NEXT ACTION」 kicker で 「今 の 状況 = 次 の 一手」 を 明示

CASE 05

状態 バッジ (新規 / 活動中 / 要フォロー / 未接触) の 色 明確化

現状 の 状態 バッジ は 全部 グレー 12px で 見分け が つか ない。 4 状態 を 別 色 (青 / 緑 / 橙 / 赤) に、 font-size 11 → 14px、 頭 に 丸 ドット を 追加 して 色覚 特性 の ある 人 に も 判別 可 に。

  • 先頭 の 丸 ドット で 色以外 の 手掛かり 追加 (アクセシビリティ)
  • 「3 ヶ月 未接触」 の 赤 バッジ を 顧客一覧 に 常時 表示 → owner が 一発 で フォロー 対象 分かる
SELECT · どれ を 実装 する か
1〜5 の 番号 で 教えて。 「全部」 と 言えば 5 個 まとめ て 実装 する。 各 案 単独 なら 1-2 時間 で PROD 反映 可能。 大幅 な 書き直し なし、 CSS + 一部 HTML 差替 の みで regression リスク 低い。

Jobs 推薦: 全部 まとめて 実装。 5 個 とも 「40-60代 の 見づらい / 押しづらい」 に 直接 効く 変更 で、 互いに 干渉 しない。 個別 実装 だと 中途半端 に 見える 可能性。

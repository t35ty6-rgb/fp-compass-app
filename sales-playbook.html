01

30秒 ピッチ

最初 の 30秒 で これ を 言えれば 続き が 聞ける。 そのまま 読める 形。

FP Compass は、 独立系 FP さん の ため の 顧客管理 と 提案準備 を 一本化 する SaaS です。 Zoom で 面談 したら、 拡張 で 自動 録音 → AI が 議事録 に 起こして 顧客カルテ に 貯まり、 「次に 何 を 提案 するか」 まで AI が 推してくれます。 月額 ¥19,800、 14日間 無料 で 全機能 使えます。
Recommended Opener

ハマる 現場 の 見分け方

  • Excel or Google スプレッドシート で 顧客管理 → LINE トーク も 追わないと 情報 が 散らかる
  • 面談 後 に 議事録 を 手書き / タイピング で 起こしてる (時間 泥棒)
  • 次 の フォロー で 「何 話したっけ」 と カルテ を 何度も 見返す
  • 複数 の 顧客 を 抱えて いて、 「誰に いつ 何 を 提案 するか」 の 優先順位 が 勘 頼み

上 の うち 2 個 以上 当てはまれば 90% クロージング 見込み。

02

誰 に 売る (3 ペルソナ)

この 3 タイプ に 絞って 話す。 銀行 / 大手代理店 の サラリーマン FP は 対象外 (承認 に 時間 かかる、 稟議 で 潰れる)。

Persona A

独立系 FP (1〜3人 事務所)

  • 顧客 30〜150 人
  • Excel or Google スプシ + LINE + 記憶
  • 面談 は Zoom 半分、 対面 半分
  • 意思決定 は 本人 = 即決 可能
  • 主戦場。 90% ここ で 決める
Persona B

保険 / 証券 の 兼業 FP

  • 本業 の CRM は 会社 支給
  • 副業 / 独立準備 で 個人客 開拓中
  • 会社 CRM に 個人客 入れられ ない
  • 安価 で 「自分の 顧客資産」 が 欲しい
Persona C

士業 (税理士 / 社労士 等)

  • FP 業務 を 顧問先 に 副次 提供
  • 顧問先 20〜80 社 の 個人相談 対応
  • 「顧問先 の 家族 まで 見て あげたい」 動機
  • 単価 高い、 継続率 高い
03

3 つの 推し (悩み → 解決)

この 3 つ が LP hero と 完全 一致。 デモ でも この 順番 で 見せる。

LINE が 散らかる

全 顧客 の LINE トーク が 顧客カルテ に 自動 束ねられる。 「あの人 何話 したっけ」 を 検索 一発 で 引ける。

議事録 が 眠る

Zoom 面談 → 拡張 で 自動 録音 → AI 文字起こし → カルテ に 貯まる。 手打ち ゼロ。 面談 直後 に 議事録 完成。

勘 で 提案 して いる

溜まった 議事録 と ライフイベント から AI が 「次に 何 を 提案 するか」 を 顧客ごと に 推奨。 提案精度 が 上がる。

04

料金 (シンプル 一本)

プラン 分け 一切 なし。 「潔い」 と 覚えて 言い切る。

FP Compass Standard
¥19,800 / 月 (税込)
1 FP = 1 アカウント。 全機能 使い放題、 顧客数 無制限、 議事録 録音 無制限。
初期費用¥0
契約期間月次 (解約自由)
無料トライアル14 日 (カード 不要)
紹介 割引-¥3,500 / 人
永久 無料6 人 紹介 で

紹介 割引 の 説明

契約後 に 「紹介 URL」 が 発行 され、 他 の FP に 共有 → その FP が 有料化 したら ¥3,500 / 月 割引。 6 人 紹介 で 永久 無料。 紹介 された 側 も 初月 半額。

紹介先 が 解約 すると 割引 も 連動 して 減る (退会 は 一方通行 だが 双方 復帰 可能)。

05

デモ の 流れ (10 分)

Zoom 画面 共有 or 対面 で PC 見せる。 この 順番 で クリック すれば 客 の 「おぉ」 が 3 回 出る。

時間画面 / 操作ポイント
0:00 ログイン 画面 Magic Link (メールリンク だけで ログイン、 パスワード なし)。パスワード 覚えなくて いい ので、 毎日 の ログイン が ストレス ゼロ です。
0:30 顧客一覧 「30 人 の 顧客 が 一覧 → 最終接点 順」 を 見せる。今日 誰 に 連絡 する べきか、 これ 1 画面 で 分かります。
1:30 顧客カルテ (1 人 開く) 基本情報 + ライフイベント 一覧 + LINE トーク + 議事録 タブ。その 人 の 全て が この 1 画面 に 集まってます。 メモ 帳 3 個 開かなくて いいんです。
3:00 Zoom 面談 開始 「急遽 面談 スタート」 → 「Zoom を 発行 して 開始」 ボタン。今 まさに 面談 する 想定 で 見て ください。 このボタン 1 個 で Zoom URL 発行 + 拡張 が 顧客セット されます。
4:00 Zoom タブ で 拡張 クリック → REC 10 秒 話す (「あー、 デモ 録音 です」)。拡張 が 「この人 と の 面談」 と 認識 済 なので、 録音 停止 したら 自動で この 顧客 の 議事録 に 貯まります。
5:30 録音 停止 → 議事録 タブ 更新 AI 文字起こし 完了 の 議事録 が カルテ に 出現。面談 が 終わった 瞬間 に 議事録 完成。 手打ち ゼロ 分 です。
7:00 AI 推奨 タブ 過去 議事録 + ライフイベント から 「次 の 提案候補」 を 3 つ 表示。全 顧客 の 次一手 を AI が 出してくれる ので、 提案 の 迷い が 消えます。
8:30 料金 説明 → 紹介 割引 「¥19,800 一本、 紹介で -¥3,500、 6人で 無料」。プラン 選び で 悩んで もらいたくない ので、 潔く 一本 に して います。
9:30 14日 無料 の 案内 → 次 の アクション その場で メール登録 → Magic Link 送信 → 「今 開いて 触って みませんか?」。カード 情報 なくて いい ので、 触って みて 合わなかったら 消して もらう だけ です。
06

想定 Q&A (10 問)

現場 で 実際 に 出た 反論 と 切り返し。 「切り返し」 は そのまま 言える 形。

既 に Salesforce (or kintone) 使ってる、 乗り換え 面倒
Salesforce は 高機能 だが FP 業務 に 特化 して ない → 議事録 も ライフイベント も AI 推奨 も 自分で 組む 必要。 FP Compass は FP 業務 だけ に 全振り して 「箱 から 出して すぐ 使える」 状態 に して あります。 「Salesforce 側 は 会社 の レポート用 に 残して、 個人客 の 提案準備 だけ こちら で 分けて 使う 先生 が 多い ですよ」
Excel で 十分 だと 思ってる、 CRM 高い
Excel の 一番 の 欠点 は 「LINE と Zoom と メール が 別 の 場所」。 一件 の 顧客 で 4 個 のアプリ を 開いて 情報 束ねる の が 毎日 発生 → 積み上げると 週 5 時間 くらい 消えて ます。 「¥19,800 で 週 5 時間 戻る、 時給 換算 で 楽勝 なので 触って みて ください」
議事録 の AI 精度 は 大丈夫?
OpenAI Whisper + Claude で 二段 で 起こして、 専門用語 (NISA / iDeCo / 変額 / 生命保険 の 商品名 等) の 認識率 も 高い。 デモ で 実 音声 聞かせながら 出せる。 「今 この 場 で 5 秒 話して 起こして 見せる ので、 精度 は 目 で 見て ください」
顧客 の 個人情報 が 心配
Google Cloud (東京 リージョン) + Firebase Auth + TLS 全通信 暗号化。 データ は 契約 FP しか 見えない (社内 の 他 FP からも 見えない)。 バックアップ 24h 毎、 監査 ログ あり。 「金融庁 の ガイドライン に 沿った 設計 に して います、 詳細な 資料 も お渡し できます」
Zoom 拡張 の インストール が 難しそう
3 分 で 終わる 手順書 用意 済み → setup-manual.html を 送れば 客 が 自分で セット アップ できる。 分からない 時 は サポート メール で フォロー。 「入れる 時 の 手順書 と、 詰まった 時 の 診断ガイド、 両方 用意 して ある ので 大丈夫 です」
AirPods 使ってて 声 が 録れない って 聞いた
v1.5.1 で AirPods 完全対応 済 (2026-07-20 リリース)。 マイク設定 ウィザード が 3 ステップ で AirPods を 認識 → HFP モード に 切替 → 録音 OK。 「AirPods は もう 大丈夫、 むしろ 今 は 内蔵mic より 音質 いい 場合 も あります」
顧客 何人 まで 使える?
無制限。 顧客数 で 課金 変わりません。 LINE トーク も 議事録 も 制限 なし。 「300 人 の 顧客 を 抱えてる 先生 でも 追加費用 ゼロ で 使えます」
解約 したい 時 は?
アカウント 画面 から 即 解約 (最低契約期間 なし)。 データ は 解約 後 30日 保管 → CSV DL 可能 → 完全消去。 復帰 も 30日 以内 なら データ 込み で 可能。 「合わなかったら いつ 辞めても いい 契約 なので、 まず 14日 触って みて ください」
14 日 の 無料 期間 中 に 課金 されないか
カード 情報 の 登録 不要。 14日 経過 → 有料化 する か 選ぶ 画面 が 出る (何も しなければ アカウント 凍結、 課金 なし)。 「触って みて 合う 感じ か 見てから カード 登録 する 順序 に して います」
高齢 の 顧客 に LINE は 難しい
LINE だけ で なく メール / SMS / 電話 の 履歴 も 全部 カルテ に 記録 できる。 LINE は オプション で、 メールだけ の 客 も 普通 に 管理 可能。 「LINE が メイン と いう 訳 じゃなく、 何 でも 束ねられる の が ポイント です」
07

クロージング 4 ステップ

迷い出したら 決めさせない。 客 の 頭 の 中 で 「試して みる か」 の 段階 で 手 を 動かす。

その場で メール登録 を 促す 「ここで メール 教えて頂けたら、 いま 登録 画面 開きます」 → 客 の PC or スマホ に Magic Link が 飛ぶ。 その場で ログイン させる。
顧客 1 人 その場で 登録 客 の 実 顧客 1 人 の 名前 と メール を 一緒 に 入れる → 「これ で もう 使え ます」 の 実感 を 与える。
setup-manual.html リンク を 送る Zoom 拡張 の インストール は 客 の 自宅 PC or 別日 でも OK → その場 では マニュアル URL だけ 送って 完結。setup-manual.html
3 日後 の チェックイン 予定 を その場で 入れる 「3日 後 に お電話 で 使い心地 聞いても いい ですか?」 → カレンダー招待 を 送る → 客 の 心 に 「試さないと」 の 期限 を 置く。
08

契約後 の 客案内 (Handoff)

売った 後 の 客 に 何 を 送る か。 テンプレ そのまま コピペ 可。

Day 0 (契約 直後) — 「セットアップ お願い メール」 テンプレ

〇〇 先生 本日 は FP Compass の ご契約 誠に ありがとう ございます。 まず 最初 に、 Zoom 面談 を 議事録 に 自動記録 する Chrome 拡張 の セットアップ を お願い します。 下記 の マニュアル 通り に 10 分 で 完了 します: ▶ 設定 マニュアル (完全版) https://app.skeleton-inc.jp/setup-manual.html もし 詰まった 場合 の 診断ガイド: https://app.skeleton-inc.jp/mic-troubleshoot.html 3 日後 くらいに お電話 で 使い心地 を お伺い させて ください。 Skeleton Inc.

Day 3 (チェックイン 電話) — 聞く こと リスト

  • 拡張 の インストール は 完了 したか (未完了 なら 一緒 に 画面 共有 で 通す)
  • 実際 の 顧客 との Zoom で 使って みたか
  • 議事録 が ちゃんと 貯まっているか (未使用 なら テスト録音 を 一緒 に やる)
  • AI 推奨 の 精度 は どうか
  • 紹介 したい FP は いるか (紹介 URL を その場で 発行 して 送る)

Day 10 (トライアル 終盤) — 有料化 の 意思確認

「そのまま 使い続けます か? カード 登録 の URL だけ 送って いい ですか?」 → 迷って いたら 3 日 延長 を 個別 で 判断。 3 回目 の 延長 は しない (依存する 客 は 有料化 しない)。

09

ワン ページ カンペ

面談 直前 に 1 分 で 見返せる 圧縮版。 スマホ で 見る 想定。

FP Compass Quick Reference

1 行 で 何?

FP 向け 顧客管理 + AI 提案準備 SaaS。 Zoom 議事録 自動化 が 目玉。

誰 に 売る?

独立 FP / 兼業 FP / FP 業務 併設 の 士業。 1〜3 人 事務所 が 主戦場。

推し 3 つ

①LINE 束ね ②Zoom 議事録 自動化 ③AI で 次一手 提案。

料金

¥19,800 / 月 一本、 14日 無料、 紹介 で -¥3,500、 6 人 で 永久無料。

デモ 順

ログイン → 顧客一覧 → カルテ → Zoom 発行 & 録音 → AI 推奨 → 料金。

クロージング

①その場 メール登録 ②顧客 1 人 登録 ③マニュアル 送る ④3日後 電話 予約。

AirPods 大丈夫?

v1.5.1 で 完全対応 済 (2026-07)。 ウィザード で 3 ステップ。

解約

いつでも 即 解約 OK、 最低契約期間 なし、 データ CSV DL 可、 30日 復帰 可能。

本日の決定事項

  • 教育資金 目標 860万 (長男 380万 / 次男 480万) を 承認、 児童手当 貯蓄 250万 差引 後 の 残 610万 を 6.5年 で 積立

  • 住宅ローン (変動 0.5% / 残 2,850万) は 借換なし・現状維持 と 決定
  • 老後資金 は 教育資金 完了 まで 月 6.8万、 完了後 月12万 に 増額 の 2段階プラン

お客様の関心事

世帯月収 手取り 68万 / 支出 52万 / 貯蓄率 24% (同世代平均 の 約2倍)。 長男 中3 (私立高校 進学 検討中) と 次男 小5 の 教育資金 準備 が 最優先。 妻 は NISA の 元本 変動 リスク に 強い 不安。

次回までのTODO

  1. 学資保険 3社 比較資料 (元本保証 の 範囲 / 途中解約 返戻率 / 契約者貸付) を 準備
  2. つみたてNISA 段階的 現金化 ロード (入学2年前 から 20% ずつ) を 図解 で 作成
  3. iDeCo 満額 拠出 の 節税額 試算 (現行 所得税率 20% 前提) を 数字 で 提示
  4. 老後 3,200万 目標 の 前提条件 (公的年金 想定額 / 生活費 想定) を 明文化 し 認識合わせ

懸念事項

NISA 暴落 リスク 大学入学 直前 に リーマン級 の 暴落 が 発生した 場合、 -30% で 現金化 になる リスク。 段階取崩 ルール で 緩和 するが 完全 排除 は 不可
高校 進路 未確定 長男 の 私立 / 公立 判断 が 教育資金 総額 に ±150万 の 影響。 中3秋 の 三者面談 後 に プラン 再調整 が 必要

議論した数字・試算

  • 教育資金 目標: 860万 (長男 380万 + 次男 480万、 私立文系 + 下宿 前提)
  • 既存 児童手当 貯蓄: 250万 / 追加 必要額: 610万
  • 月 積立額: 8万 × 6.5年 = 624万 到達
  • ローン 借換 試算: 諸費用 60万 / 回収 期間 8年 → メリット薄
  • 老後 目標: 3,200万 (65歳時点、 iDeCo 満額 + NISA 余枠)
補足メモ

妻 は 数字 に 強く、 その場 で 電卓 を 叩いて 確認 する タイプ。 説明資料 は 「結論 の 数字」 → 「根拠 の 数字」 → 「前提条件」 の 順序 で 構成 すると 納得 が 早い。 夫 は 変動リスク に 敏感、 リスク管理 の ルール化 が 意思決定 の 鍵。 iDeCo は 次回以降 の 提案 で 満額 → 段階的 に 説明。

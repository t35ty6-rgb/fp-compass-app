FP Compass · 設定マニュアル

Zoom 連携 の 設定 手順

Zoom Marketplace で FP Compass 用 の アクセス権 と 録画完了通知 を 設定 して、 面談 の 議事録 を 自動 で FP Compass に 届く 状態 に する 手順書。 直接 リンク で 1 クリック で 該当画面 に 飛ぶ ので、 迷わ ず 3 分 で 終わる。

Section 01

アクセス権 (スコープ) を 追加 2 分

FP Compass が Zoom の データ を 取得 する ため の 権限 4 つ を、 Zoom Marketplace の アプリ に 追加 します。 下 の 直接 リンク で Scopes 画面 に 一発 で 飛べます。

1

Scopes 画面 を 直接 開く (Chrome ログイン 必要)

下 の 「Copy」 を 押して URL を コピー → Chrome の アドレスバー に 貼付 → Zoom アカウント で ログイン (2要素認証 まで 完了 させる)。

https://marketplace.zoom.us/develop/apps/anOSyfukSYClWMKm1Avf1Q/scope

↗ Scopes 画面 を 開く

これ は owner (FP Compass 本体) の 直接 リンク。 別 会社 で FP Compass 契約 する 場合 は、 各 client 自身 の Zoom アプリ の app ID に 差し替え て 使う。
2

「+ Add Scopes」 で スコープ 4 つ を チェック

「+ Add Scopes」 ボタン を 押して 出た モーダル の 検索欄 に 下 の 名前 を 入力 して、 該当 する 権限 に チェック。 4 つ 全部 終わったら Done → Continue → Save。

  • 録画 の 一覧 取得cloud_recording:read:list_user_recordings:admin
  • 録画 と 文字起こし の 取得cloud_recording:read:recording:admin
  • ユーザー 情報 の 取得user:read:user:admin
  • プラン情報 の 取得 (任意)billing:read:plan_information:admin
コツ: 検索欄 に cloud_recording と 入れる と 2 つ 一気 に 候補 が 出る。 user:read は 「User (Admin) 単一 users」 の 意味 の もの を 選ぶ。
Section 01 完了 確認
Save 後、 Scopes タブ に cloud_recording:read:list_user_recordings cloud_recording:read:recording user:read:user billing:read:plan_information の 4 つ が 表示 されて いれば OK。
Section 02

録画完了通知 を 登録 3 分

Zoom で 会議 の 録画 が 終わったら、 FP Compass に 自動 で 通知 が 届く 設定 を 追加 します。 下 の 直接 リンク で Feature 画面 に 一発 で 飛べます。

1

Feature 画面 を 直接 開く

https://marketplace.zoom.us/develop/apps/anOSyfukSYClWMKm1Avf1Q/feature

↗ Feature 画面 を 開く

2

Event Subscriptions を ON → 「+ Add Event Subscription」

ページ の 中央 の 「General Features」 に ある Event Subscriptions の トグル スイッチ を 押して グリーン に する。 直後 に 「+ Add Event Subscription」 ボタン が 現れる ので 押す。

3

名前 + 通知先 URL を 貼付

開いた フォーム に、 下 の 値 を そのまま Copy して 貼付:

  • Subscription NameRecording Completed
  • Event notification endpoint URLhttps://asia-northeast1-skeleton-fp-compass-632026.cloudfunctions.net/zoomRecordingWebhook
4

「+ Add Events」 → Recording → All Recordings have completed → Done → Save

フォーム 内 の 「+ Add Events」 を 押す と モーダル が 開く。 続けて 4 動作:

  1. 左サイドバー で Recording を 押す (Meeting が 初期選択 に なってる ので 必ず 切替)
  2. 右側 で All Recordings have completed の チェックボックス を 押す
  3. 右下 の Done を 押す (モーダル 閉じる)
  4. フォーム 下部 の Save を 押す
Save 後、 subscription 一覧 に 「Recording Completed」 が 追加 される。 右側 に ✏ 鉛筆 と 🗑 ゴミ箱 の アイコン が 出る。
5

✏ 鉛筆 で 編集画面 開く → 「Validate」 で グリーン ✓

subscription 一覧 の 「Recording Completed」 の 右側 の ✏ 鉛筆 マーク を 押す (🗑 ゴミ箱 じゃない 方)。

編集画面 が 開く → URL 欄 の 下 の 「Validate」 button を 押す → 数秒後 に グリーン ✓ (Validated) 表示 に なれば 登録完了。

Validate は 2 秒 以内 に 成功 する はず。 Skeleton の サーバー を 常時 稼働 (warm) に して ある ので、 timeout 起きない。 もし 失敗 したら Section 04 「困った時」 参照。
6

「Continue」 → Activation タブ で グリーン ✓ 確認

Feature 画面 の 右下 の 「Continue」 を 押す → 左メニュー の Activation タブ に 移動。

Your app is activated on the account の 緑チェック が 表示 されて いれば、 全 設定 完了。

もし 「app can not be activated yet due to missing」 の 警告 が 出た 場合 は、 Feature タブ に 戻って 「Validate」 が グリーン ✓ に なって いる か 再確認。 Validate されて いない と Activation が 通らない。
Section 02 完了 確認
Feature タブ の Event Subscriptions 一覧 に 「Recording Completed」 サブスクリプション が グリーン ✓ で 表示 されて いれば OK。
Section 03

動作 確認 1 分

設定 が 全部 完了 した か どう か を、 実 面談 1 本 で テスト します。

1

FP Compass で テスト 面談 を 開始

FP Compass の 顧客カルテ で 「🎙 面談 を 開始」 → 「今すぐ Zoom」 を 押して、 Zoom タブ で 10 秒 ほど 声出し して 「テスト、 これ 入って ます」 等 話す。

2

Zoom タブ を 閉じて 5-15 分 待つ

Zoom タブ を 閉じる と 会議 が 終了 → Zoom Cloud で 録画 + 文字起こし の 処理 (5-15 分 かかる) → 完了 したら Skeleton の エンドポイント に 通知 が 届く。

3

FP Compass の 面談履歴 タブ で 議事録 を 確認

該当 顧客 の カルテ を 開いて 「面談履歴」 タブ を 見る。 新しい 議事録 が 追加 されて いれば 成功。

追加 された 議事録 に は:

  • 「Zoom 面談」 の 記録
  • Whisper より 精度 高い Zoom cloud 文字起こし
  • Claude が 生成 した 5 セクション の 議事録

が 含まれ ます。

全 設定 完了
面談履歴 に 議事録 が 自動 追加 されて いれば、 Zoom → FP Compass の 全 自動化 が 稼働 開始。 以降 は 面談 する だけ で 議事録 が 溜まる 状態 に なる。
Section 04

困った時

各 手順 で よく ある トラブル と 対処法。 発生 頻度 の 高い 順 に 並んでる。

1

「URL validation failed. Try again later.」 が 出た

Skeleton の サーバー 側 で 3 秒 の Zoom timeout に 引っかかった。 もう一回 Validate button を 押す だけ で 直る (前回 で サーバー が warm 状態 に なった ため)。

それ でも 失敗 する 場合:

  1. URL 欄 に 余分 な スペース / 全角 文字 が 入って ない か 目視 確認
  2. URL を 一旦 全消し → 下 の 正 URL を 再貼付:
    https://asia-northeast1-skeleton-fp-compass-632026.cloudfunctions.net/zoomRecordingWebhook
  3. Save → Validate 再実行
  4. それ でも 失敗 なら Skeleton の Jobs に 連絡
2

「Validate」 button が 出て こない

Subscription を Save まだ 押して ない 可能性。 一覧 に 「Recording Completed」 が 表示 されて いれば Save は 済 → subscription の 右側 の ✏ 鉛筆 マーク を 押して 編集画面 を 開くと Validate button が 見える。

それ でも 見えない なら:

  • ページ を 一旦 リロード (⌘R / Ctrl+R)
  • Feature タブ を 再 訪問 (左メニュー の Feature を 再 click)
3

「Sign In」 に 戻される (login loop)

Zoom Marketplace の session は idle で 5-10 分 で 切れる。 途中 で 席 を 離れて 戻ったら 「Sign In」 に なってた 場合 が これ。

右上 の 「Sign In」 押して login し直せば OK。 それ まで の 入力 内容 (subscription name / URL 等) は Zoom 側 で 保存 されて ない ので、 やり直し に なる 可能性 が ある。 login 済 の 状態 で 一気 に 進める の が コツ。

4

Activation で 「Your app can not be activated yet」 が 出る

Activation の 前提条件 が 満たされて ない。 警告 の 下 に 出て いる 「missing information」 の 内容 で 判断:

  • 「Event Notification Endpoint URL needs validation」 → Section 02 Step 5 の Validate を 実行 (グリーン ✓ に する)
  • 「Scopes missing」 → Section 01 で 4 個 の scope を チェック して Save

Feature タブ → 該当 subscription で Validate 完了 → もう一度 Activation タブ に 戻って 状態 を 再確認。

5

面談 したのに 議事録 が FP Compass に 出て こない

以下 を 順 に 確認:

  1. Zoom Cloud 側 の 処理 は 5-15 分 かかる。 面談終了 直後 に 議事録 を 期待 しない。 30 分 待って から 確認
  2. 面談 が Zoom Cloud 録画 に なって いた か 確認 (Local 録画 だと 対象外)。 zoom.us → Recordings で 該当 会議 が Cloud Recordings 側 に あれば OK
  3. 音声文字起こし が ON に なって いる か 確認 (zoom.us → Settings → Recording → 「Audio transcript」 を ON)
  4. 該当 顧客 の 面談履歴 タブ を リロード
  5. それ でも 出て こない なら Skeleton の Jobs に 連絡 (会議 の Meeting ID を 添えて)
6

Secret Token が 変わった / 再生成 したい

Feature タブ の 上部 の 「Secret Token」 欄 に 「Regenerate」 button が ある。 押す と 新しい Token が 発行 される (旧 Token 即 失効)。

Regenerate 押した 後 は 必ず 新 Token を Skeleton の Jobs に 連絡 (Skeleton 側 で 反映 しない と 全 webhook が signature mismatch で 落ちる)。

Zoom の Web で 2 つ の スイッチ が 青 (ON) か 確認 する。 これ が OFF だと Zoom が 録画 と 文字起こし を 作って くれない ので 議事録 も 出て こない。

  • Zoom Web の 設定 ページ を 開く 下 の 緑 ボタン で ワン クリック。 Zoom に ログイン が 求められたら ログイン する (メニュー 左 「レコーディング」 タブ に 自動 で 移動 する)。 Zoom 設定 を 開く
  • 「クラウドレコーディング」 が 青 (ON) に なっている 見出し 「クラウドレコーディング」 の 右 に ある トグル スイッチ。 グレー (OFF) だったら 押して 青 に する。
  • 「オーディオ文字起こしを作成する」 が 青 (ON) に なっている 「クラウドレコーディングの詳細設定」 の 見出し の 下 に ある チェックボックス。 グレー だったら 押して 青 に する。
  • 「自動レコーディング」 で 「クラウド上にレコーディングする」 が 選ばれて いる (推奨) これ を ON に すると、 面談 開始 の 瞬間 に 自動 で Zoom Cloud 録画 が 始まる の で 「録画 ボタン 押し 忘れ」 事故 が なくなる。 OFF でも 手動 で 「レコーディング」 ボタン 押せば OK だ が、 owner に は ON 推奨。

FP Compass

Chrome 拡張機能 の 入れ方

Zoom で 相手 の 声 も 議事録 に 入る ように する 設定
所要 時間 5分 / 費用 0円

この 手順 の 流れ (全 6 ステップ)

  1. Chrome を 開く
  2. 拡張機能 の 設定 画面 に 行く
  3. 「デベロッパー モード」 を ON に する
  4. フォルダ を 読み込む
  5. ツールバー に ピン 留め する
  6. 動作 テスト を する
1
Chrome を 開く 10秒

Mac の Dock (画面下 の アプリ列) から Google Chrome を クリック して 開いて ください。 Chrome が Mac に 入って ない 場合 は こちら から DL。

こんな アイコン
赤 / 黄 / 緑 の 3色 の 丸い アイコン。 「Google Chrome」 と 書いて ある。
2
拡張機能 の 設定 画面 に 行く 10秒

Chrome 上部 の URL バー (Web ページ の アドレス が 出る 場所) に、 下 の 文字 を そのまま コピー して 貼り付けて Enter キー を 押す。

chrome://extensions/
こんな 画面 が 出る
タイトル に 「拡張機能」 と 書いて ある。 既に 入って いる 拡張 が 一覧 で 出て いる 場合 も ある。
3
「デベロッパー モード」 を ON に する 5秒

「拡張機能」 の 画面 の 右上 に 「デベロッパー モード」 と いう スイッチ が ある。 それ を クリック して ON に する (青く なる)。

画面 右上 の こんな スイッチ
拡張機能         デベロッパー モード ON
これ で 「読み込み」 ボタン が 表示 されます。 心配 しないで、 ONに する だけ で 何 も 壊れません。
4
フォルダ を 読み込む 30秒

ステップ 3 で 出て きた 左上 の 「パッケージ 化 されて いない 拡張機能 を 読み込む」 ボタン を クリック。

Finder が 開く の で、 デスクトップ → 「FP-Compass-拡張機能」 フォルダ を 選んで 「選択」 ボタン。

選ぶ フォルダ の 場所
📁 デスクトップ
  └ 📁 FP-Compass-拡張機能 ← これ を クリック して 「選択」
もし デスクトップ に 「FP-Compass-拡張機能」 が 無い 場合:
Finder で ⌘ + ⇧ + G を 押して、 出て きた 入力欄 に 下 を コピペ:
~/.skeleton-fp-compass-chrome-ext
こう 出れば 成功
  • 拡張機能 の 一覧 に 「FP Compass 議事録レコーダー」 が 追加 された
  • version 1.0.0 が 表示 されて いる
  • スイッチ が ON (青) に なって いる
5
ツールバー に ピン 留め する 15秒

Chrome の 右上 に パズル ピース の アイコン (🧩 みたいな 形) が ある の で クリック。

出て きた リスト の 「FP Compass 議事録レコーダー」 の 横 の 📌 ピン アイコン を クリック。

ピン 留め すると こう なる
🧩   🔵 FP   ...ほか の アイコン
ツールバー に FP の アイコン が 常に 出て、 いつでも クリック できる 状態 に なる。
6
動作 テスト を する 2分

実際 に 録音 が 動く か 試して みる。 Zoom じゃ なくて YouTube で テスト できる ので 手軽。

  1. YouTube で 適当 な 動画 を 開いて 再生 (音 が 出て いれば OK)
  2. ツールバー の 🔵 FP アイコン クリック
  3. popup で 「🎙 Zoom タブ 録音 を 開始」 クリック
  4. 「共有 する タブ を 選択」 の dialog で YouTube タブ を 選ぶ → 「共有」
  5. マイク の 許可 dialog が 出たら 「許可」
  6. アイコン に 赤 の「REC」バッジ が 出れば 録音 中
  7. 10秒 くらい 待って、 popup を もう一度 開いて 「■ 録音 を 停止」 クリック
  8. 「✓ 停止 しました」 と 出れば 成功
こう なれば 完璧
  • 録音 中 に REC バッジ が 出た
  • 停止 で エラー なく 完了
  • popup に 「送信 中…」 の 緑 メッセージ
🎉

設定 完了 !

これで Zoom で AirPods 使って も 相手 の 声 が 議事録 に 入る よう に なりました。
次 の Zoom 面談 の 時 に: Zoom Web 版 (zoom.us) で 面談 開始 → 拡張 アイコン → 録音 開始。

⚠ うまく いかない 時

Q. 「拡張機能」 の 画面 が 出ない

Chrome の URL バー に chrome://extensions/ が 正しく 入って いるか 確認。 コピペ の 時 に 空白 が 入って ない か チェック。 それでも ダメ なら Chrome を 再起動。

Q. デスクトップ に フォルダ が 無い

Step 4 の 「もし デスクトップ に 無い 場合」 の 手順 を 実行。 Finder で ⌘+⇧+G → ~/.skeleton-fp-compass-chrome-ext を 貼り付けて Enter。

Q. 「読み込み エラー」 が 出る

選んだ フォルダ が 間違って いる 可能性。 フォルダ の 中 に「manifest.json」 が ある か 確認。 無い なら 1つ 上 の フォルダ を 選び直す。

Q. タブ 選択 dialog が 出ない

Chrome を 最新版 に 更新 (Chrome メニュー → 「Google Chrome について」)。 Chrome 100 以上 が 必要。

Q. マイク許可 dialog が 出ない

Chrome 設定 → プライバシー と セキュリティ → サイト設定 → マイク で 「サイト は マイク を リクエスト できる」 が ON か 確認。

Q. REC バッジ が 出ない

popup を 一度 閉じて、 拡張 アイコン を もう 一度 クリック して 状態 を 再確認。 それでも ダメ なら Chrome を 再起動 して 再度 試す。

Q. 全部 ダメ

Chrome の F12 (もしくは ⌥+⌘+I) で 「Console」 タブ を 開いて、 赤い エラー メッセージ を 全部 スクショ 撮って Jobs に 送って ください。

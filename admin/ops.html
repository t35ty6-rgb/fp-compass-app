📖 OPS マニュアル

FP Compass オーナー専用 運営ダッシュボード。 売上原価 と ユーザー需要 を 一画面で 把握。

このページの 役割
① 「💰 コスト」 = AI(Whisper + Claude) の 利用料金 を 全テナント横断 集計
② 「🔍 質問」 = お客様が LINE で 聞いてきた 質問を カテゴリ別に 蓄積・分析
③ 「📖 マニュアル」 = 仕組み・価格根拠・トラブルシュート の 解説

💰 コスト ダッシュボード

何が見えるか

  • 当月 API 合計コスト (Whisper / Claude 内訳)
  • 本日 / 1顧客あたり平均 / 最大消費テナント / 録画分数
  • 日別推移グラフ (過去30日)
  • テナント別 ランキング (録画分・Whisper・Claude・合計)
  • 直近 50件 アクティビティ feed

記録される タイミング

Cloud Run の 以下 3つの endpoint 呼出時 に Firestore usage_logs に 1 doc 追加:

  • /api/process-recording — 録画 → AI議事録 (Whisper + Claude Sonnet)
  • /api/generate-deliverable — 提案書/シミュレータ生成 (Claude Sonnet)
  • /api/classify-questions — Q&A 自動分類 (Claude Haiku)

🔍 質問 アーカイブ

仕組み

各 FP が 顧客モーダルの 「Q&A」 タブを 開くと、 そのお客様の LINE 履歴 全部を AI (Claude Haiku) で 分類。 結果は question_archive Firestore に 1質問 = 1 doc で 蓄積。 重複は merge (同テナント × 同顧客 × 同質問テキスト)。

分類カテゴリ (8種)

  • NISA・iDeCo (制度・配分・引出)
  • 教育資金 (学資保険・大学費用)
  • 住宅ローン (繰上返済・借換・控除)
  • 老後資金 (年金・退職金)
  • 保険 (生命・医療・がん)
  • 相続・贈与
  • 税金
  • その他

事業 活用

  • 多い質問 = LP / 営業資料 で 先回り 解決
  • カテゴリ偏り = 教材 / プロダクト 改良 の 一次データ
  • テナント別 トレンド = どの FP が どの領域 強いか 把握

🔧 トラブルシューティング

コスト ダッシュボードが 空

  • 当月の Whisper / Claude 呼出が ゼロ → 録画 / Q&A タブを 1度 開く と 表示
  • Firestore 読込権限エラー → オーナーemail で ログインしているか 確認

質問アーカイブが 空

  • 各 FP が 顧客モーダル → Q&A タブ を 開いていない → FP に依頼

変更履歴 / 価格更新

USD-JPY 為替 固定 = 150。 改定時は proxy/index.js の PRICING 定数 + USD_JPY を 更新 → gcloud run deploy。

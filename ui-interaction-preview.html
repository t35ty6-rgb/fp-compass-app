FP COMPASS · INTERACTION PATTERN · 5 案

「人 を 押す → カルテ が 出る」 の 5 パターン

前回 の 「見た目 の 案」 じゃ なくて、 操作 感 (interaction) の 案 を 5 つ 提示。 サロンワークス 風 の 「客 を 押す → 詳細 が 開く」 の 動き 方 の バリエーション。 各 案 に 「一覧 状態 (左)」 と 「1 人 選んだ 状態 (右)」 を 並べた。 選ばれた 案 で 実 デモ (interactive) を build する。

CASE A

左 一覧 + 右 詳細 (Split View)

LSTEP · Notion · Slack 風

左 に 顧客 一覧 が **常時 表示**、 右 に 選んだ 客 の カルテ。 押す たび に 右 が 切り替わる。 一覧 と 詳細 が 同時 に 見え、 「次 の 客 に すぐ 移れる」。 LSTEP や Slack 系 の 業務ツール で 一番 主流 の パターン。

SELECT · どの 動き 方 で 実 デモ を build する か
A / B / C / D / E の 番号 で 教えて。 選ばれ たら **実 データ 15 名 · 全画面 遷移 が 動く interactive デモ** を build して STG に up。

Jobs 推薦: CASE B (全画面 カルテ) か CASE E (Notion 系)。
  • CASE B — 40-60代 に 一番 分かりやすい。 サロンワークス と 同 感覚。 スマホ でも 同じ 動き で 完璧。 「今 何 見てる か」 が 常に 明確。
  • CASE E — 客 数 が 多い FP先生 (30 名 超) が 「顧客 台帳 を 眺めて 誰 に 何 する か 決める」 使い 方 なら 最適。 一覧 が 常に 見え、 顔 と 名前 で 覚えやすい。
A (LSTEP 風) は 現行 と 発想 が 近い ので 「変わった 感」 が 弱い、 C/D は スマホ 感 が 強く PC 業務 で は やや 特殊、 と 判定。

🎤 対面 面談 mode · 実 動作 test

これ は 本番 の 「対面 で 面談 (音声だけ 録音)」 button と 同じ 動作 を する デモ。 押した ら 何 が 起きる か、 実際 に 体験 して 確認 する 用。

手順
1. 下 の 「面談 開始」 button を 押す
2. 画面 が dark blue の 「面談 記録 中」 に なる
3. 同時 に 左下 隅 に 小さい window が 開く (本番 で は Zoom · ここ で は デモ 用 の Google)
4. 左下 window が 出て いれば popup 許可 済 = 本番 も 動く
5. 出ない = popup ブロック 中 · 手順 は 下 に

popup が ブロック された 場合:
Chrome の URL 欄 右端 に 「🚫」 マーク が 出る · click → 「常に 許可」 → 再 test。
Safari の 場合: 設定 → Web サイト → ポップアップ ウィンドウ → skeleton-inc.jp を 「許可」。

面談 開始前 に FP Compass で 顧客カルテ を 開き、 Zoom を 発行。 拡張機能 は その顧客に 自動で 紐付いた 状態 で 待機します。 Zoom タブ で 拡張アイコン を 1回押せば 録音が 始まり、 タブを 閉じれば 自動で 停止 → 議事録が 該当顧客に 保存されます。 AirPods / Bluetooth ヘッドホン でも 相手の声が 拾えます。

面談 の 流れ

初回だけ 拡張機能 の インストール が 必要です (別ページ)。 2回目以降は 下の 4アクション で 完了。

1

顧客カルテ を 開く FP Compass

面談 する 顧客 の カルテ を 開きます。 上部 の ＋急遽 面談スタート を 押して、 📹Zoom を発行して開始 を 選択。

この瞬間 に 拡張機能 は その顧客の 情報 を 受け取り、 アイコン が 緑▶ に 光ります。
2

Zoom URL を 開く 新しい タブ で

FP Compass が 発行した Zoom URL を 新しい タブ で 開きます (「FPとして Zoom に参加 + 録画開始」 ボタン は Chrome 標準の 画面共有 方式、 拡張機能 方式 を 使う 場合 は 別 タブ で URL を 開くだけ で OK)。

既存 の 予約された Zoom URL でも 同じ です。 Zoom Web版 (zoom.us) の タブ が 開いていれば 何 でも 対象 に なります。
3

Zoom タブ で 拡張アイコン を 押す Chrome 右上

大事 な のは 「Zoom タブ を 表示した 状態 で」 Chrome 右上 の 拡張アイコン を クリック する こと。 popup に 「◯◯さん の 録音 を 開始」 と 顧客名 が 表示 され、 🎙 録音 を 開始 ボタン を 押すと 収録 スタート。

!
FP Compass タブ や 新規タブ で 押すと 「Extension has not been invoked」 エラー が 出ます。 Chrome の 安全機能 で、 Zoom タブ に 切り替えて 押し直せば 解決 します。
4

面談 を 終える Zoom タブ を 閉じる

Zoom タブ を 閉じる だけ で 自動停止 + 自動送信。 popup で ■停止 を 押しても OK。 FP Compass 側 で 「✓ ◯◯さん の 音声 受信」 の トースト が 出て、 議事録 が 該当顧客 に 紐付いた 状態 で 生成 されます。

議事録 生成 (Whisper 文字起こし + Claude 要約) は 5〜10分 かかります。 完了 したら 顧客カルテ の 議事録タブ に 表示 されます。

うまくいかない とき

典型的 な 3ケース と 対処。 それ 以外 が 出たら popup の エラー文 を そのまま 事務局 に 共有 してください。

Extension has not been invoked for the current page

原因: Zoom タブ 以外 (FP Compass タブ / 新規タブ / chrome:// 内部ページ) で 拡張アイコン を 押した。
対処: Zoom タブ に 切り替え、 もう一度 アイコン を クリック。

Chrome pages cannot be captured

原因: chrome:// や 拡張機能 の 設定ページ を 開いた 状態 で 押した。
対処: Zoom Web版 (zoom.us) の タブ を 開いてから 押す。

popup で 「顧客 未選択」 のまま

原因: FP Compass 側 で 「Zoom発行」 を 押していない、 または ページ を リロード して 状態が 消えた。
対処: 顧客カルテ に 戻り、 「急遽 面談スタート」 → 「Zoom発行」 を 押し直す。

よくある 質問

運用中 に よく 聞かれる 6つ。

拡張機能 の 更新 は どう する?
Chrome の アドレスバー に chrome://extensions/ と 入力 → 「FP Compass 議事録レコーダー」 の 🔄 更新 ボタン。 バージョン 表示 が v1.1.0 以上 に なれば OK。 新バージョン 配布時 は FP Compass 事務局 から アナウンス します。
AirPods / Bluetooth ヘッドホン で 相手の声 が 拾える?
拾えます。 従来 の Mac マイク経由 だと 「相手の声 が Bluetooth 側 に 直接送られる」 ため マイク で 拾えず 議事録 に 入らない 問題 が ありました。 この 拡張機能 は Zoom タブ音声 を 直接 取得する ので、 Bluetooth ヘッドホン でも 相手の声 が 100% 収録 されます。
途中 で Zoom タブ を 誤って 閉じたら?
それまで 録音 していた 分 は 自動送信 されます。 面談 が まだ 続いていた 場合、 Zoom タブ を 再度 開いて 拡張アイコン から 「録音を開始」 → 再開 (2つの 録音 に 分かれて 議事録 生成 されます)。
議事録 生成 が 遅い / 出ない 時 は?
Whisper の 文字起こし は 音声 60分 で 5〜10分 かかります。 60分 以上 待って も 出ない 場合 は 事務局 に 連絡 してください。 音声ファイル は 送信済 で サーバー に 保存 されている ので、 再生成 が 可能 です。
マイク の 使用 許可 を 求められた ら?
「許可」 を 選択 してください。 拡張機能 は Zoom タブ音声 (相手の声) と マイク音声 (自分の声) を 合成 して 収録 します。 マイク が 未許可 だと 自分の声 が 議事録 に 入らず、 相手 の 一方的 な 発言 だけ の 議事録 に なります。
複数 顧客 と 続けて 面談 する 時 は?
1件 終わる ごと に FP Compass で 次の 顧客カルテ を 開き、 「Zoom発行」 を 押し直して ください。 拡張機能 は 最後に 「Zoom発行」 された 顧客 だけ を 記憶 します (前の顧客 の arm は 上書きされる)。

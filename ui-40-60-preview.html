FP COMPASS · UI PROPOSAL · 40-60代 向け

FP先生 の 顧客一覧 画面 · 5 案

現行 UI は 30代 前提 で 情報 密度 高め。 実 ユーザー の FP先生 は 40-60代 が 中心 で、 現行 は 「文字 小さい / 何 どこ か 分からない」 の フィードバック 常態。 5 案 で 40-60代 向け の 別 パターン を 提示。

文字 16-18px 以上 タップ 領域 52px+ コントラスト WCAG AAA 専門用語 最小化 familiar patterns 優先
CASE 01

紙 台帳 風 (Ledger Book)

FP事務員 · 経理 感覚

昔 の 経理 台帳 の 見た目 の まま デジタル 化。 一覧性 と 見慣れ 感 が 一番 強い。

左 に 現行 と 同じ サイドバー、 中央 に 太い 黒枠 で 囲んだ 表。 各行 の 高さ は 現行 の 倍 の 68px、 名前 は 18px 太字、 コントラスト は 白 × 濃 ink で 目 に 優しい。 事務員 系 の FP先生 が 一番 「見慣れて る」 感じる 想定。

CASE 03

今日 に フォーカス

忙しい 先生 · 予定 中心

「今日 やる こと」 が 一番 上、 顧客一覧 は 下 に 小さく。 迷わず に 今日 の 面談 に 進める。

ホーム 画面 の 90% を 「今日 の 面談 予定」 に 割く。 何時 に 誰 と 何を するか が 一目、 「面談 開始」 ボタン が 巨大。 顧客一覧 は 下 に 小さく (直近 接触 順 5 名 + 全 一覧 リンク)。

CASE 04

3 ボタン ホーム (ATM 風)

初心者 · 迷わない 用

ATM や 郵便局 の 端末 の ように 「今 何 する?」 の 大 button 3 つ だけ。 迷う 余地 なし。

ホーム 画面 に 巨大 な 3 button だけ (「今日 の 予定」 「新しい 客 を 登録」 「面談 を 始める」)。 押した 先 の 画面 で また 単一 目的 の button で 誘導。 IT 苦手 な 先生 でも 迷い ゼロ。

CASE 05

Excel / 表計算 風

数字 好き · 見て 決める 型

馴染み の Excel そっくり の 見た目。 40-60代 が 日常 で 一番 触ってる ツール。

Excel の 表 と 同じ 見た目 (ヘッダ グレー、 行 交互 色、 罫線)。 上部 に Excel の ツールバー 風 の 操作 button (並び替え / フィルター / 追加)。 「クリック して 開く / 編集 する」 の Excel 的 直感 が そのまま 通用。

SELECT · どの UI で 実装 する か 教えて
CASE 01〜05 の 番号 で 教えて。 「01 と 03 の 混合」 (台帳 の 中身 + Today ホーム) 等 の 組み合わせ も OK。 選ばれ たら 現行 FP Compass 全画面 を その 方向 で 書き直し 開始。

Jobs 推薦:
  • CASE 03 (Today-first) — 忙しい 先生 に 一番 刺さる。 迷い ゼロ。
  • CASE 04 (3 ボタン) — IT が 一番 苦手 な 先生 に 一番 優しい。
  • CASE 01 (台帳) — 見慣れ 感 一番 高い。 事務員 タイプ FP 向け。
02 (カード) は 装飾多め、 05 (Excel) は 現行 と 発想 が 近い の で 差別化 弱い、 と 私 の 判定。

FP Compass 議事録レコーダー

自分の声だけ 入らない — 拡張機能 の バグ で は なく、 Mac か Chrome の 設定 で 直せます

Zoom 面談 の 議事録 に 自分の声 が 入ってない 時 の 診断ガイド。 上から 順 に 3ステップ 試すと、 だいたい これ で 直ります。 所要 3分。

Symptom

議事録 に 相手の声 だけ 入って、 自分の声 が 入ってない。 or Console に mic 拒否 or 取得失敗 と 出る。

この 症状 は だいたい Mac 側 か Chrome 側 の マイク許可 が 抜けてる ため。 拡張機能 の バグ で は ありません。

STEP 1 / 3
Mac に Chrome の マイク使用 を 許可

macOS が Chrome 自体 に マイク を 触らせて ない パターン。 8割 は これ で 直ります。

1

「システム設定」 を 開く

画面 左上 の アップルメニュー (🍎) → 「システム設定…」

2

「プライバシーとセキュリティ」 → 「マイク」

左のサイドバー を 下 に スクロール → 「プライバシーとセキュリティ」 をクリック → 右側 の リスト から 「マイク」 をクリック。

3

「Google Chrome」 の トグル を ON に

アプリ一覧 が 出るので、 「Google Chrome」 の 右側 の スイッチ を 確認。

プライバシーとセキュリティ > マイク
ZZoom
Google Chrome
← これ ON
✎メモ

🎯 緑 に なってれば OK。 グレー なら クリック して ON に する → Chrome を 再起動 (⌘ Q → もう一度 開く)。

✓
「Google Chrome」 の 右 の スイッチ が 緑 で、 白丸 が 右側 に あれば OK。

STEP 2 / 3
Chrome 側 で マイク が ブロック されて ないか 確認

過去 に Zoom や 拡張 の マイク許可 を うっかり 「ブロック」 押してた パターン。

1

Chrome の 新しい タブ で URL を 開く

アドレスバー に 下記 を 貼って Enter:

chrome://settings/content/microphone
2

「ブロック」 リスト を 確認

「マイクのアクセスをブロックするサイト」 の リスト を 見る (古い Chrome では 「マイクの使用を許可しないサイト」 と 表記 されてる 場合 も あり)。

  • https://zoom.us や https://*.zoom.us が 入って いれば 削除 (右 の ゴミ箱 マーク)
  • chrome-extension://… が 入って いれば 削除
✓
「ブロック」 リスト に Zoom も 拡張 も 入って なければ OK。

STEP 3 / 3
マイク デバイス が 正しく 選ばれてる か

AirPods や 外付け マイク の 切替 で、 想定 と 別の デバイス に なってる パターン。

1

Mac の 「サウンド」 設定 で 入力 を 確認

システム設定 → 「サウンド」 → 「入力」 タブ。

ここで 選ばれてる デバイス が 今 使いたい マイク か 確認。 AirPods 使ってる 時 は 「AirPods マイク」、 内蔵 の 時 は 「MacBook Pro の マイク」 が 選ばれてる はず。

下 の 入力 レベル の バー を 見ながら 「あー」 と 声 を 出して、 バー が 動けば その マイク は 生きてます。

✓
選ばれてる デバイス で 入力レベル が 動く なら、 マイク 自体 は 動作 中。
Verify

試して みる

  1. Chrome を 一旦 全部 終了 (⌘Q) → もう一度 開く
  2. FP Compass で 「Zoom を 発行して 開始」 → Zoom タブ で 拡張 アイコン を 1回 クリック
  3. 初回 は Chrome が 「マイク を 使用しますか?」 の ポップアップ を 出す ので 「許可」 を 押す
  4. 5秒 くらい 「あー」 と 声 を 出す → 面談 終了
  5. FP Compass の 議事録 タブ で 自分の声 が 入ってれば 完了
ここまで 試して、 自分の声 が 入って いれば 解決 です。 それでも 議事録 に 自分の 声 が 入らない 場合 は、 下 の 連絡先 に Chrome の バージョン (chrome://version の 最初の1行) と 症状 を 送って ください。

よくある 質問

Console の 赤いエラー [auto-start] failed: Extension has not been invoked… は?

これ は Chrome の 仕様 で、 バグ で は ありません。 拡張 は 自動 で 録音 を 始め たがった が、 Chrome の セキュリティ で 弾かれた、 だから 「あなた が 拡張 アイコン を 押して ね」 という 意味。 Zoom タブ で 拡張 アイコン を 1回 クリック すれば 録音 開始 します。

「マイク を 使用しますか?」 の ポップアップ が 出ない

STEP 2 で 過去 に 「ブロック」 押してる 可能性 大。 chrome://settings/content/microphone を 開いて ブロック リスト を 空 に して ください。

設定 を 変えた のに、 まだ 録音されない

Chrome と あわせて Zoom も 一旦 終了 (⌘Q) → もう 一度 開き 直して ください。 マイク設定 は 「再起動 した 時」 に 反映されます。

AirPods 使うと 相手 の 声 も 入らない

それ は 別の 事象 (macOS の 仕様) です。 音声設定ガイド の Chrome拡張 方式 を 見て ください。

会社支給 Mac で 管理者 権限 が ない

STEP 1 (システム設定 → マイク) は 管理者 権限 が いる 場合 が あります。 会社 の 情シス に 「Google Chrome に マイク の 使用 を 許可 して 欲しい」 と 依頼 してください。

これ でも 直らない 時 は

サポート に メール を お願いします → support@skeleton-inc.jp
その 時 に Chrome の バージョン (アドレスバー に chrome://version を 貼って 最初の1行 を コピー) と macOS の バージョン (🍎 → 「この Mac について」) を 添えて 頂ける と 早く 特定 できます。

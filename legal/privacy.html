SKELETON INC. · PRIVACY POLICY v2.0

プライバシーポリシー

制定日: 2026-06-06 最終更新: 2026-06-06

スケルトン株式会社 (以下「当社」) は、 SaaS サービス「FP Compass」 (以下「本サービス」) における個人情報の取扱いについて、 個人情報保護法その他関連法令を遵守し、 以下のとおりプライバシーポリシー (以下「本ポリシー」) を定めます。

第1条 (取得する個人情報)

当社は本サービスの提供に際し、 次の個人情報を取得します:

対象取得する情報
FP (本サービス利用者)氏名、 メールアドレス、 屋号 / 法人名、 パスワード (SCRYPT ハッシュ化)、 IP アドレス、 利用ログ
エンドユーザー (FP の顧客)FP が入力する氏名、 連絡先、 家族構成、 相談履歴、 LINE 履歴、 議事録 等
代理店氏名、 屋号、 メアド、 電話、 SNS URL、 業界経験、 銀行口座 (報酬振込用)
申請者・問い合わせ者申請フォーム / お問い合わせフォームに入力された情報

第2条 (利用目的)

  1. 本サービスの提供、 認証、 サポート、 不正利用防止
  2. オンライン面談の録画・音声の文字起こし、 および AI による議事録の自動生成・要約
  3. LINE 公式アカウントを通じたエンドユーザーとのメッセージ送受信
  4. 料金請求、 代理店報酬計算・支払
  5. サービスの改善、 統計分析、 AI モデル学習 (個人特定不可な集計データのみ)
  6. 利用規約違反の調査、 法令対応、 紛争解決
  7. サービスに関する重要なお知らせ・通知の送付

第3条 (データの管理体制)

当社は本サービスのデータを Google Cloud (Firebase / Firestore) 上に保管しており、 以下の技術的・組織的安全管理措置を講じています:

  • 暗号化: 通信は TLS 1.3、 パスワードは SCRYPT ハッシュ、 保存データは AES-256 で暗号化
  • テナント分離: Firestore セキュリティルールにより、 各 FP は自社のデータのみ閲覧可能
  • バックアップ: Point-in-time recovery (7日)、 Daily (7日)、 Weekly (12週) の3層
  • アクセス制御: 当社内では Skeleton 代表取締役のみが管理者権限を保有
  • 監査ログ: 全ての read / write / delete 操作を audit_logs に記録
  • 所在地: サーバーは Google Cloud asia-northeast1 (東京) リージョン

第4条 (第三者提供)

当社は、 法令に基づく場合を除き、 ご本人の同意なく個人情報を第三者に提供しません。 ただし、 以下の業務委託先には業務上必要な範囲で情報を共有します:

  • Google Cloud Platform (本サービスのインフラ提供)
  • Stripe (決済処理。 クレジットカード情報は Stripe が PCI DSS 準拠で取り扱い、 当社サーバーには保存しない)
  • クラウドサイン (代理店との電子契約締結)
  • Anthropic PBC (AI 議事録要約・AI 返信文の生成。 面談の文字起こしテキスト および LINE 履歴が Anthropic に送信されるが、 モデルの学習には使用されない契約。 サーバー所在地は米国)
  • OpenAI, L.L.C. (Whisper API による対面面談の録音音声の文字起こし。 モデルの学習には使用されない契約。 サーバー所在地は米国)
  • Zoom Video Communications, Inc. (オンライン面談の通信・クラウド録画・音声の文字起こし。 サーバー所在地は米国)
  • LINEヤフー株式会社 (LINE 公式アカウントを通じたエンドユーザーとのメッセージ送受信)
  • Resend, Inc. (パスワード再設定・通知メールの配信。 メールアドレスと本文のみ。 サーバー所在地は米国)
  • Expo Application Services, Inc. (iOS アプリのプッシュ通知トークン中継。 サーバー所在地は米国)
  • Apple Inc. (Sign in with Apple による認証、 APNs によるプッシュ通知配信)

外国にある第三者への提供

上記のうち Anthropic PBC・OpenAI, L.L.C.・Zoom Video Communications, Inc.・Resend, Inc.・Expo Application Services, Inc.・Apple Inc.・Stripe, Inc. は 日本国外 (主に米国) の事業者です。 米国には日本と同等の個人情報保護制度があるとは認められていないため、 当社は各社との契約により、 個人情報の保護に関する措置を継続的に確保しています。 なお本サービスの主たるデータ保管先である Google Cloud Firestore は asia-northeast1 (東京) リージョンを使用しています。

エンドユーザーの個人情報の取扱いについて

FP が本サービスに入力するエンドユーザー (相談者) の個人情報について、 個人情報取扱事業者としての本人対応義務 (利用目的の通知、 同意の取得、 開示・訂正・削除請求への対応) は FP に帰属します。 当社は FP からの委託を受けて当該情報を processing する立場です。 FP は、 エンドユーザーの音声を録画・文字起こしし AI 要約する旨を、 面談前にエンドユーザーへ説明し同意を得てください。

第5条 (代理店プログラムにおける情報共有)

代理店経由で本サービスに登録された FP の情報のうち、 以下の項目のみ 代理店本人のダッシュボードで開示されます:

  • FP の屋号 / 法人名
  • 登録日
  • 有料化・解約等のステータス

代理店には FP のエンドユーザー (相談者) の情報は一切開示されません。

第5条の2 (データの保存期間と削除)

当社は取得した情報を、 以下の期間保存し、 経過後は削除または統計処理により個人を特定できない形に加工します:

対象保存期間
FP アカウント情報・エンドユーザー情報・面談記録・議事録契約期間中。 解約後 30 日 (この間に CSV/JSON でのデータ書き出しが可能)
オンライン面談の録画・音声・文字起こし契約期間中 (Zoom クラウド上の保管期間は Zoom 側設定に従う)
LINE メッセージ履歴契約期間中。 解約後 30 日
決済・請求に関する記録法令に基づき 7 年間 (法人税法・電子帳簿保存法)
監査ログ (audit_logs)取得から 1 年間
エラーログ・アクセスログ取得から 90 日
プッシュ通知トークンサインアウトまたは端末変更まで (即時削除)

解約後 30 日を経過したデータは、 当社の定期処理により削除されます。 処理の実行タイミングにより、 実際の削除完了までに最大 60 日を要する場合があります。 即時削除をご希望の場合は support@skeleton-inc.jp までご連絡ください。

第6条 (お客様の権利)

お客様は、 ご自身の個人情報について、 次の権利を行使できます:

  • 開示請求: ご自身の情報の開示を求めることができます
  • 訂正・削除: 情報の訂正・削除を求めることができます
  • データポータビリティ: 解約時、 全データを CSV/JSON で自動 DL 可能
  • 利用停止: 同意の撤回 / 利用停止を求めることができます

これらの権利行使は support@skeleton-inc.jp までご連絡ください。 本人確認後、 速やかに対応します (原則7営業日以内)。

第7条 (Cookie・解析ツール)

本サービスはサービスの改善のため、 以下のツールを利用しています:

  • Firebase Analytics: 利用状況の集計 (IP 匿名化済)
  • Cookie / localStorage: ログイン状態の保持、 紹介トラッキング

ブラウザ設定で無効化することも可能ですが、 一部機能が制限される場合があります。

第8条 (未成年者)

本サービスは事業者向けであり、 未成年者の利用を想定していません。 万一未成年者の個人情報を取得していたことが判明した場合、 速やかに削除します。

第9条 (本ポリシーの改定)

当社は、 法令の改正、 サービスの変更等に応じ、 本ポリシーを改定することがあります。 重要な変更については本サービス上で30日前までに通知します。

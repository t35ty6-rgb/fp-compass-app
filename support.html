よくある ご質問

  • LINE 連携 が うまくいきません

    お客様 の LINE 公式アカウント の Channel Access Token / Secret を 「LINE 設定」 画面 に 正しく 入力 して ください。 期限 切れ の 場合 は LINE Developers Console で 再発行 が 必要 です。

  • Zoom URL が 発行 されません

    「Zoom 連携」 画面 で Account ID / Client ID / Client Secret を 設定 して ください。 Zoom Marketplace で Server-to-Server OAuth App を 作成 する 必要 が あります。

  • 議事録 が 生成 されません

    面談 の 録音 データ が 保存 されて いる か 確認 して ください。 「面談履歴」 画面 で 音声 ファイル が アップロード 済み なら AI 処理 に 通常 30秒〜3分 かかります。

  • 解約 したい です

    「マイページ → プラン管理」 から 解約 手続き が できます。 解約 後 も 現 プラン 期間 終了 まで ご 利用 頂けます。

  • データ を エクスポート したい です

    顧客 データ の CSV エクスポート は 「顧客リスト → メニュー → エクスポート」 から 可能 です。

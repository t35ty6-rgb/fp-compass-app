💡 Zoom credentials の 取得方法

1. Zoom Marketplace を開く → 「Server-to-Server OAuth」 アプリ を 新規作成
2. 「App Credentials」 タブ で Account ID / Client ID / Client Secret 取得
3. 「Scopes」 タブ で meeting:write:meeting:admin 等の Meeting 系 scope 追加
4. 「Activation」 タブ で アプリ Activate
5. この画面 に 3つ 貼り付け → 保存

サブスク管理

カード変更 / 領収書ダウンロード / 解約手続き

Stripe のサブスク管理画面 が開きます。 以下が セルフ で 行えます:
・ カード情報の変更 (有効期限切れ ・ 紛失時)
・ 過去の領収書 ・ 請求書 PDF ダウンロード
・ 解約手続き (当月末 まで 利用可能、 翌月 から 課金停止)

解約前に「全データをJSONでダウンロード」 することを推奨します。

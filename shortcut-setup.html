名前 と 共有シート 設定

2.1

画面 上部 の 「新規 ショートカット」 の 右 の ▼ or i を タップ

iOS 17 以降 は 上部 の 「新規 ショートカット」 の 右 に 下 矢印 (▼) や (i) アイコン が ある。 iOS 16 以前 は 右上 の 3 点 (⋯) → 「詳細」。

2.2

詳細 パネル で 「名前」 欄 に FP Compass アップロード と 入力

後 で iPhone の 共有 シート で この 名前 で 出る。 分かり やすい 名前 を つけて OK。

2.3

同じ 詳細 パネル で 「共有 シート に 表示」 を ON に する

スイッチ を 緑 に。 これ を ON に しない と Voice Memos の 共有 メニュー に 出て こ ない。

⚠ ここ が 一番 重要 「共有 シート に 表示」 が OFF の まま だと、 全 手順 完了 して も Voice Memos から 呼び 出せ ない。
2.4

「受信 する 種類」 で メディア だけ ON に する

下 に 「受信 する 種類」 の 一覧 が 出る (テキスト / URL / メディア / ファイル …)。 「メディア」 の チェック だけ 残して 他 は 全部 OFF。

期待: Voice Memos の 共有 で は 音声 が 「メディア」 種別 で 渡って くる ため、 これ に チェック 必要。
2.5

「完了」 or 「×」 で 詳細 パネル を 閉じる

元 の ショートカット 編集 画面 に 戻る。

3 / 9

API キー を 変数 に 保存

これ から やる こと (概要) 「テキスト」 アクション で API キー の 文字列 を 埋め込む → 「変数 を 設定」 で 「API_KEY」 と いう 名前 の 変数 に する。 後 の URL 呼び出し で ヘッダ に 使う。
3.1

画面 下部 の 検索 バー に テキスト と 入力

下部 に アクション 検索 バー が ある。 表示 され ない 時 は 画面 中央 の 「アクション を 追加」 ボタン を 一度 タップ。

3.2

検索 結果 の テキスト (T の アイコン) を タップ

「テキスト」 と いう 名前 の アクション が 追加 される。 中央 に 白い 入力 欄 が 出る。

3.3

「テキスト」 の 入力 欄 を タップ → API キー を ペースト

入力 欄 を 長 押し → 「ペースト」 で さっき コピー した キー (32文字) を 貼り 付ける。

期待: 入力 欄 に o-5_ayHoq4RCZjzAUgkjbff0_EB7UYJ_ (実 キー) が 表示 される。
3.4

もう 一度 検索 バー に 変数 を 設定 と 入力 して 変数 を 設定 を タップ

「変数 を 設定」 アクション が 追加 される。 中身 は 「変数 の 名前」 欄 と 「入力」 欄 の 2 つ。

  • 「変数 の 名前」 欄 に API_KEY と 入力 (大文字 · 半角 アンダー スコア)
  • 「入力」 欄 は 自動 で 上 の 「テキスト」 が 選ばれて いる (青 の 「テキスト」 と 表示)

客 リスト を FP Compass から 取得

5.1

検索 バー に URL と 入力

複数 候補 が 出る。 「URL」 と 「URL の 内容 を 取得」 の 2 つ が 主要。

5.2

URL (地球 アイコン) を タップ して 追加

アクション 「URL」 が 追加 される。 中央 に 「apple.com」 の プレースホルダ。

5.3

「apple.com」 部分 を タップ して 以下 を 貼付

https://fp-compass-webhook-527726449426.asia-northeast1.run.app/api/mobile/customers

長 押し で 全 選択 → 削除 → 上 の URL を コピペ が 楽。

5.4

検索 バー に URL の 内容 を 取得 と 入力 → URL の 内容 を 取得 タップ

アクション 「URL の 内容 を 取得」 が 追加 される。 自動 で 上 の 「URL」 が 入力 に 入る。

5.5

「URL の 内容 を 取得」 の 下 の 「>」 (詳細 展開) を タップ

展開 する と 「方法」 「本体」 「ヘッダ」 の 設定 が 出る。

  • 「方法」: GET の まま (default)
  • 「ヘッダ」: 「ヘッダ を 追加」 を タップ → キー X-FP-Mobile-Key と 入力 → 値 欄 を タップ → 変数 パネル から 「API_KEY」 を 選択
期待: ヘッダ 欄 に 「X-FP-Mobile-Key: [API_KEY 変数]」 の 1 行 が 追加 される。
6 / 9

客 名前 の リスト を 作って 選択 メニュー 化

これ から やる こと レスポンス は {customers: [{id,name}, ...]} 形式。 「辞書 の 値 を 取得」 で customers を 抜き、 「各 項目 を 繰り返す」 で 名前 だけ を 集め、 「リスト から 選択」 で 客 を 選ぶ。
6.1

検索 バー に 辞書 の 値 を 取得 → 辞書 の 値 を 取得 タップ

「キー」 欄 に customers と 入力。 「辞書」 欄 は 自動 で 上 の 「URL の 内容 を 取得」 の 結果 が 入る。

6.2

検索 バー に 各 項目 を 繰り返す → 各 項目 を 繰り返す タップ

繰り返し ブロック が 追加 される。 「繰り返し」 と 「繰り返し の 終了」 の 間 に アクション を 入れる。 「入力」 は 自動 で 上 の 「辞書 の 値」 が 入る (customers リスト)。

この ブロック の 中 に、 検索 バー で 辞書 の 値 を 取得 を 追加 → キー name。

期待: 繰り返し の 中 で 各 客 の name だけ が 取り 出さ れる。 ブロック の 外 に 出た とき 「繰り返し の 結果」 という 変数 に 全 client 名 の 配列 が 入る。
6.3

検索 バー に リスト から 選択 → リスト から 選択 タップ

アクション 「リスト から 選択」 が 追加 される。

  • 「リスト」 欄: 自動 で 「繰り返し の 結果」 が 入る (客名 一覧)
  • 「>」 展開 → 「プロンプト」 欄 に 誰 の 面談 ですか? と 入力
7 / 9

選択 した 名前 に 対応 する 客 ID を 見つける

コツ 「リスト から 選択」 で 得た の は 名前 の 文字列 だけ。 対応 する ID を 引く ため、 もう 一度 客 リスト を 繰り返して 名前 一致 で ID を 変数 に 保存 する。
7.1

検索 バー に 各 項目 を 繰り返す → タップ

2 つ 目 の 「各 項目 を 繰り返す」 が 追加 される。 「入力」 欄 を タップ → 変数 パネル で 「辞書 の 値」 (Chapter 6.1 で 抜いた customers) を 選択。

7.2

繰り返し の 中 に 「if」 文 を 追加

検索 バー に if → If (青 の 分岐 アイコン) を タップ。

  • 「入力」 欄: 「繰り返し 項目」 (現在 の 客 辞書) が 自動 で 入る、 その まま で は 辞書 全体 が 比較 対象 に なる の で…
  • 「入力」 欄 を タップ → 「辞書 の 値 を 取得」 を 挟む → キー name → 「取得 元」 に 「繰り返し 項目」
  • 「条件」: が 次 と 一致 を 選択
  • 右 の 値 欄: 変数 パネル で 「選択 された 項目」 (Chapter 6.3 の 結果) を 選択
7.3

「If」 の 中 に 「変数 を 設定」 を 追加

検索 バー に 変数 を 設定 → タップ。

  • 「変数 の 名前」: CUSTOMER_ID
  • 「入力」: 「辞書 の 値 を 取得」 を 挟む → キー id → 「取得 元」 に 「繰り返し 項目」
期待: If ブロック 内 で 名前 が 選択 と 一致 した とき、 その 客 の id が CUSTOMER_ID 変数 に 保存 される。
8 / 9

音声 を FP Compass に POST

8.1

検索 バー に URL の 内容 を 取得 → タップ

2 つ 目 の 「URL の 内容 を 取得」 が 追加 される。 これ が アップロード 用。

8.2

URL 欄 に 以下 を 貼付

https://fp-compass-webhook-527726449426.asia-northeast1.run.app/api/mobile/upload
8.3

「>」 展開 → 「方法」 を POST に 変更

タップ して 選択 リスト から 「POST」。

8.4

「要求 の 本文」 を フォーム に 変更

タップ して 「フォーム」 (multipart/form-data 相当) を 選択。 下 に フィールド 追加 UI が 出る。

8.5

フィールド を 2 つ 追加

「フィールド を 追加」 を 2 回 タップ して 2 行 作る。

  • 1 行 目: キー audio, 種類 ファイル, 値 は 変数 パネル で 「AUDIO」 変数 を 選択
  • 2 行 目: キー customerId, 種類 テキスト, 値 は 変数 パネル で 「CUSTOMER_ID」 変数 を 選択
⚠ 「種類」 を 間違えない audio は 必ず 「ファイル」、 customerId は 「テキスト」。 間違える と 400 error に なる。
8.6

「ヘッダ」 で X-FP-Mobile-Key = API_KEY を 追加

Chapter 5.5 と 同じ 手順。 キー X-FP-Mobile-Key、 値 は 「API_KEY」 変数。

9.2

検索 バー に 結果 を 表示 → 結果 を 表示 タップ

TROUBLESHOOTING
「呼び出せません でした」 の エラー API キー が 間違って いる 可能性。 FP Compass の アカウント 設定 で 再発行 → Shortcut の 「テキスト」 アクション に 貼り 直し。
「共有 メニュー に 出て こない」 Chapter 2.3 の 「共有 シート に 表示」 が OFF の 可能性。 詳細 パネル で 確認。
500 エラー が 返って くる 音声 サイズ が 30MB 超 か 判定 幻覚 で 拒否 されて いる 可能性。 短めの 録音 (30 秒 〜 数分) で 再 test。
「信頼 されて いない ショートカット」 で 弾かれる iPhone 設定 → ショートカット → 「信頼 されて いない ショートカット を 許可」 を ON。

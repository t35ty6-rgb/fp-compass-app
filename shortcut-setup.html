iPhone 音声 upload
セットアップ

ボイスメモ の 録音 → 議事録 自動 生成 まで。 準備 3 分、 使用 1 タップ。

使う 時 の 流れ (準備 完了 後)

1.ボイスメモ で 録音 → 共有 → 「FPコンパス保存」 タップ (音声 が iCloud に 保存)
2.ホーム 画面 の 「FPコンパス upload」 アイコン タップ (Safari で 開く)
3.客 を 選ぶ → 「音声 を upload」 → 完了 メッセージ を 待つ
1 共有 用 ショートカット を install (30 秒)

ボイスメモ の 共有 メニュー に 「FPコンパス保存」 を 追加。 タップ 1 回 で 音声 を iCloud に 保存 して くれる。

ショートカット を install
  1. iPhone Safari で 上 の button を タップ
  2. 「Shortcuts で 開く」 → 青 の 「ショートカット を 追加」 を タップ
  3. Shortcuts app に 「FPコンパス保存」 が 出れば OK
2 upload ページ を ホーム 画面 に 追加 (30 秒)

Safari 内 の 客 選択 & upload ページ を、 ホーム 画面 の アイコン から 1 タップ で 開ける ように する。

upload ページ を 開く
  1. 上 の button で app.skeleton-inc.jp/upload.html を 開く
  2. Safari の 下 の 共有 button (□↑) を タップ
  3. 「ホーム 画面 に 追加」 を タップ → 「追加」
  4. ホーム 画面 に 「FPコンパス upload」 アイコン が 出れば OK
✅ ここ まで 完了 で 準備 終わり。 以降 は 上 の 「使う 時 の 流れ」 3 step だけ で 使える。

初回 使用 時 の 詳細 手順

A. ボイスメモ で 録音 → 保存
  1. iPhone 「ボイスメモ」 で 面談 を 録音 → 停止
  2. 録音 タイル を タップ → 下 の 共有 button (□↑)
  3. 共有 メニュー から 「FPコンパス保存」 を タップ
    ※ 出て こない 場合 → 共有 メニュー の 一番 下 「アクション を 編集」 で 「FPコンパス保存」 を ON
  4. 「✅ 音声 を 保存 しました」 alert が 出たら OK (音声 は iCloud Drive の Shortcuts / FPコンパス / latest.m4a に 保存)
B. upload ページ で 客 を 選んで upload
  1. ホーム 画面 の 「FPコンパス upload」 アイコン タップ
  2. 初回 のみ FP Compass に login (Google または メール)
  3. 「客 を 選ぶ」 で 対象 の 客 を 選択
  4. 「音声 ファイル」 の 枠 を タップ → 「ブラウズ」 → iCloud Drive → Shortcuts → FPコンパス → latest.m4a を 選択
  5. 「音声 を upload」 を タップ → progress bar が 進 む → ✅ upload 成功 が 出れば OK
  6. 3-5 分 後、 admin の 客 ページ → 議事録 tab に 議事録 出現
💡 補足
· 録音 品質: 「設定 → ボイスメモ → オーディオ 品質」 を 「圧縮」 に (1時間=約15MB)
· 同じ ファイル 名: 毎回 「latest.m4a」 で 上書き 保存 される (問題 なし、 upload 済 の 音声 は server 側 に 別途 保存)
· Wi-Fi 必須 じゃない: 4G/5G でも upload 可能 (1時間 音声 で 約 15MB)
⚠ よく ある トラブル
· 共有 メニュー に 「FPコンパス保存」 が 出ない → 共有 メニュー 一番下 「アクション を 編集」 → 「FPコンパス保存」 を ON
· upload ページ で 「login が 必要」 → メール & パスワード or Google で login (FP Compass admin と 同じ アカウント)
· 「客 リスト 取得 失敗」 → account.html で 「API キー を 発行」 が 未完了 の 可能性。 発行 して 再試行
· upload 失敗 → 「音声 を upload」 を もう 一度 タップ で 再試行 可

Voice Memos → ワンタップ 議事録 化

iOS ショートカット アプリ の 画面 に そのまま 出て くる 文字 だけ を 使って 進める マニュアル。 「その文字 を 検索 バー に コピペ する」 「その文字 を タップ する」 の 2 動作 だけ で 迷わず 進める 構造。

マニュアル の 読み 方

各 サブ ステップ は 3 種類 の ラベル で 何 を すれば いい か を 示す:

検索 アクション を 追加 — この 文字 を iOS の アクション 検索 バー に 入力 する
タップ 共有 シート に 表示 — この 文字 が 画面 に 出る の で タップ or スイッチ ON
入力 API_KEY — この 文字 を そのまま 入力 欄 に コピペ or 手入力

iOS 版 で 文字 が 微妙 に 違う 時 (例: 「アクション を 追加」 が 「アクション 追加」 に なって いる 等) は、 先頭 3-4 文字 だけ で 検索 して も ヒット する。 例えば 「アクション」 と 打つ だけ で ほぼ 出る。

重要: iOS Shortcut の 基本 パターン (これ を 先 に 理解)

アクション を 追加 する と、 「入力」 欄 に 「1 個 上 の アクション の 出力」 が 自動 で 入る。 これ が iOS Shortcut の 最大 の 落とし穴。 例えば:

状態 (困る 例):
「変数 AUDIO を API_KEY に設定」
← ここ の API_KEY は 自動 で 入った 値。 これ を 「ショートカットの入力」 に 変え たい 場合:

動作:
1. 青バブル API_KEY を タップ
2. 下 から 変数 選択 パネル が 出て くる
3. パネル の 一番 上 の 「ショートカットの入力」 を タップ

結果:
「変数 AUDIO を ショートカットの入力 に設定」

マニュアル 中 で 「差替」 「変更」 「選択」 と 書いて ある 場所 は 全部 この パターン。 「タップ で 青バブル を 差 替える」 を 反復 する だけ。

「呼び出せません でした」 の エラー API キー が 間違って いる 可能性。 FP Compass の アカウント 設定 で 再発行 → 「テキスト」 アクション に 貼付 し 直し。
「400 エラー」 が 返って くる Chapter 8.5-8.6 で 種類 を 間違え て いる 可能性 が 高い。 audio = 「ファイル」、 customerId = 「テキスト」 を 再確認。
「500 エラー」 が 返って くる 音声 サイズ が 30MB 超 の 可能性。 短めの 録音 (30 秒 〜 数分) で 再 test。
「信頼 されて いない ショートカット」 で 弾かれる iPhone 設定 → ショートカット → 「信頼 されて いない ショートカット を 許可」 を ON。

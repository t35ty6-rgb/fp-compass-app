iPhone ショートカット セットアップ
ガイド

iPhone ボイスメモ → 共有 → 1タップ で 議事録 自動 生成。 setup 5 分。

Shortcut file を ダウンロード

まず iPhone Safari で 下 の button を タップ → 「Shortcuts で 開く」 → 「ショートカット を 追加」 で install。 その後 STEP 2-3 で 自分 の API キー を 1 箇所 貼付。

Shortcut を ダウンロード
対応: iOS 15 以上 / macOS Monterey 以上
セットアップ の 全 flow (4 step で 完結):
STEP 1. 上 の button で Shortcut file を ダウンロード + install
STEP 2. 「API キー を 発行」 で 自分 の キー を コピー
STEP 3. Shortcut 内 の 「テキスト」 1箇所 に 自分 の キー を 貼付
STEP 4. ボイスメモ の 共有 メニュー から 起動 → 議事録 自動 生成

1Shortcut を install

  1. iPhone Safari で この ページ を 開き、 上 の 「Shortcut を ダウンロード」 button を タップ
  2. 「Shortcuts で 開く」 → 青 の 「ショートカット を 追加」 button を タップ
  3. iPhone Shortcuts app に 「FP-Compass-Upload-v18」 が 追加 された こと を 確認
💡 AirDrop でも OK: 別 の 人 の iPhone に は Mac Finder から AirDrop で 同じ .shortcut file を 送 る と 上 と 同じ flow で install できる。

2自分 の API キー を 発行

  1. iPhone Safari で https://app.skeleton-inc.jp/account.html を 開く
  2. 自分 の アカウント で ログイン
  3. 下 に スクロール → 「iPhone ショートカット 連携」 セクション
  4. 紫 の 「API キー を 発行」 button を タップ → OK
  5. 黄色 枠 に API キー が 表示 → 「コピー」 button で コピー

① 紫 button で 発行 → ② 黄色 枠 の キー を確認 → ③ コピー button で コピー

⚠ 重要: API キー は 二度と 表示 され ない (安全 の ため)。 忘れたら 「再発行」 で 新しい キー を 作る。 Shortcut に 貼付 済 の キー も 一緒 に 更新 が 必要。

3Shortcut 内 の API キー を 書き換え

  1. iPhone Shortcuts app で 「FP-Compass-Upload-v18」 を 探す
  2. タイル 右上 の 「⋯」 → 「編集」
  3. 上 から 2番目 の 「テキスト」 action (オレンジ の アイコン) を 探す
  4. 中 の 長い 文字列 を 全選択 → 削除
  5. STEP 2 で コピー した 自分 の API キー を 貼付
  6. 右上 「完了」 で 保存

「テキスト」 action の 中 の 文字列 (6fc1... 等) を 全選択 → 削除 → 自分 の キー を 貼付

⚠ 触っては いけない ところ:
· 「変数 API_KEY を 入力 に設定」 の 部分 → そのまま
· URL (https://fp-compass-webhook-…) → そのまま
· 他 の action → 全部 そのまま
直す の は 「テキスト」 の 中 の 文字列 だけ

4使い方 (日常運用)

  1. iPhone 「ボイスメモ」 で 面談 を 録音
    💡 事前 準備: 「設定 → ボイスメモ → オーディオ 品質」 を 「圧縮」 に (1時間=約15MB に 収まる)
  2. 録音 タップ → 下 の 共有 button (□↑) → 「FP-Compass-Upload-v18」 タップ
  3. 初回 のみ 「Web に データ を 送信 を 許可 しますか?」 → 「1度だけ許可」 タップ
  4. 客 リスト メニュー → 対象 の 客 を タップ
  5. 数秒 で ✅ 音声 受信 完了 · 議事録 生成 中… popup 表示 (これ で 「受け付け 完了」)
  6. 1〜5 分 後、 app.skeleton-inc.jp → 議事録 tab → 客 カード に 議事録 出現
💡 補足 機能:
· 1時間 以上 の 録音 → server 側 で 自動 圧縮 + Whisper 処理 (upload 制限 なし)
· transcript + summary + 次回質問予測 が 自動 生成
· 面談 対象 客 を 事前 に 固定 したい 場合 → account.html の 「モバイル 送信先 (デフォルト 客)」 で 選択 → 保存 (以降 は 客 選択 メニュー 不要)

トラブル シューティング

  • 認証 エラー → API キー 貼付 ミス。 STEP 2-3 やり直し
  • 「客 が 見つかり ません」 → FP Compass admin に 客 が 未登録。 admin panel で 客 を 追加
  • popup が 空 → 音声 が 25MB 超 で server 側 で 詰まった 可能性。 「設定 → ボイスメモ → 圧縮」 に 変更 して 再録音
  • 議事録 が 生成 されない → 音声 が 短い or 無音 の 可能性。 30秒 以上 の 実 会話 で 再送信

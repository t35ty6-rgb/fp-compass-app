iOS SHORTCUTS SETUP

Voice Memos → ワンタップ 議事録 化

iPhone で 録音 した 音声 を、 共有 メニュー から 3タップ で FP Compass の 議事録 に 変換 する ショートカット を 作ります。 初回 のみ 5分 の セットアップ で、 以降 は ずっと 使えます。

準備: アカウント 設定 の 「iPhone ショートカット 連携」 で API キー を 発行 して コピー して おいて ください。 下 の 手順 の 途中 で 貼付 する 場所 が あります。
1iPhone で「ショートカット」アプリ を 開く

iOS 標準 アプリ の ショートカット を 開き、 右上 の + を タップ して 新規 ショートカット を 作成。

2共有 メニュー に 表示 する 設定

右上 の 情報 (i) ボタン → 共有 シート に 表示 を ON。 「受信 する 種類」 で 「メディア」 だけ に チェック (他 は OFF)。

名前 を 「FP Compass アップロード」 に 設定。

3APIキー を テキスト として 保存

アクション 検索 で テキスト → 追加。 中身 に アカウント 設定 で コピー した API キー を 貼付。

下 の アクション 変数 を 設定 → 変数 名 「API_KEY」、 値 は 上 で 貼付 した テキスト。

4共有 メニュー から 受け 取った 音声 を 変数 に 保存

アクション 変数 を 設定 → 変数 名 「AUDIO」、 値 は 「ショートカットの入力」 (自動 で 候補 に 出る)。

5客 リスト を 取得

アクション URL の 内容 を 取得 を 追加。

  • URL: https://fp-compass-webhook-527726449426.asia-northeast1.run.app/api/mobile/customers
  • 方法: GET
  • ヘッダ: X-FP-Mobile-Key → 値 は 上 で 作った 「API_KEY」 変数 を 選択

次 に 辞書 の 値 を 取得 → キー 「customers」。

6客 名前 の リスト を 作って メニュー 表示

アクション 各 項目 を 繰り返す (Repeat with Each) → 中 に 辞書 の 値 を 取得 (キー 「name」)。

ループ 後 の 結果 は 「繰り返し の 結果」 として 集計 される。

アクション リスト から 選択 (Choose from List) → 入力 は 「繰り返し の 結果」、 プロンプト 「誰 の 面談 ですか?」。

7選ばれた 名前 に 対応 する ID を 見つける

もう 一度 各 項目 を 繰り返す で customers 全件 を 舐めながら、 if ブロック で 「辞書.name = 選択 した 項目」 なら 「辞書.id」 を 変数 CUSTOMER_ID に 保存。

※ Shortcuts app の 「辞書.name = 選択 名」 の 判定 は 「if」 アクション の 「値 が 次 と 一致 する」 を 使う。

8音声 を FP Compass に 送信

アクション URL の 内容 を 取得 を 追加。

  • URL: https://fp-compass-webhook-527726449426.asia-northeast1.run.app/api/mobile/upload
  • 方法: POST
  • 要求 の 本文: フォーム (multipart/form-data)
    • キー audio = 値 「AUDIO」 変数 (種類: ファイル)
    • キー customerId = 値 「CUSTOMER_ID」 変数 (種類: テキスト)
  • ヘッダ: X-FP-Mobile-Key → 「API_KEY」 変数
9結果 を 表示

アクション 辞書 の 値 を 取得 → キー 「note」 (レスポンス の 中身 = 「◯◯ 様 の 議事録 が 生成 されました」)。

その 出力 を 結果 を 表示 (Show Result) で 表示 して 終了。

🎉 セットアップ 完了

Voice Memos で 録音 → 3 点 メニュー (⋯) → 共有 → FP Compass アップロード を タップ → 客 選択 → 数十秒 で 議事録 tab に 反映 されます。

うまく いかない 時:
・API キー を 再発行 して 貼付 し直す (アカウント 設定 の 「iPhone ショートカット 連携」)
・iPhone 設定 → ショートカット → 「信頼 されて いない ショートカット を 許可」 が OFF の 場合 は ON に
・音声 file が m4a / mp3 / wav 以外 の 場合 は 拒否 される
・500エラー が 返って くる 場合 は 客 側 の Firestore doc に 問題 の 可能性 → support@skeleton-inc.jp

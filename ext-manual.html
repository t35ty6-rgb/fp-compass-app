拡張機能 の 使い方

Zoom 面談 の 音声 を 自動 で 録音 → 議事録 生成 する Chrome 拡張機能。 AirPods でも 相手 の 声 が 拾える、 面倒な 画面共有 ダイアログ 不要。 v1.3.0 で 「FP Compass の Zoom button 押す だけ で 自動起動」 に なった。

SECTION 01 既に install 済 → v1.3.0 に 更新

v1.1.0 以前 を 使ってる 場合、 CSP bug で 拡張機能 が 認識されない 状態 でした。 v1.3.0 で 修正 済 + 「Zoom button 押す だけ で 自動起動」 に なった ので、 必ず 更新 してください。

1Chrome で 拡張機能 ページ を 開く

Chrome の URL バー に chrome://extensions/ と 打つ → Enter。

(または Chrome 右上 の … メニュー → 「拡張機能」 → 「拡張機能 を 管理」)

2「FP Compass 議事録レコーダー」 を 見つける

一覧 の 中 に FP Compass 拡張 が 出ている はず。

CHROME://EXTENSIONS/ の 表示
🧩
FP Compass 議事録レコーダー
1.1.0 → 1.3.0 に なれば OK
⟳ 更新
3「更新」 button を クリック

拡張機能 の カード の 右下 (or ページ 右上) に ⟳ 更新 button がある。 これを click → 数秒 で version が 1.3.0 に なる。

ℹ 「更新」 button が 見つからない 場合: 拡張機能 ページ 右上 の 「デベロッパーモード」 switch を ON に すると、 各 拡張 の 下 に 「更新」 が 出る。
4FP Compass タブ を リロード

https://app.skeleton-inc.jp/ タブ を Cmd + Shift + R (ハードリロード) で 開き直す。

これで 新 拡張 v1.3.0 が FP Compass 側 でも 認識される。

SECTION 02 初めて → 新規 install

Chrome Web Store 未公開 の ため、 zip を DL → unpacked mode で 手動 install する 形。 一度 install すれば 以降 は 自動更新可能。

1拡張機能 zip を ダウンロード

下 の button を click → FP-Compass-拡張機能.zip が Downloads に落ちる (13KB)。

📥 zip を DL する

2zip を 展開 して 好きな場所 に 置く

Downloads の zip を ダブルクリック → FP-Compass-拡張機能 フォルダ が できる。 これを 消さない場所 (Documents や Desktop) に 移動。

⚠ フォルダ を 消したり 移動 したり しない: unpacked mode の 拡張 は フォルダ を 指す ので、 消すと 拡張 が 使えなく なる。
3Chrome の 拡張機能 ページ で 「デベロッパー モード」 ON

Chrome の URL バー に chrome://extensions/ → Enter。 右上 の 「デベロッパー モード」 の switch を ON に する。

4「パッケージ化 されて いない 拡張機能 を 読み込む」 を クリック

デベロッパー モード ON に なる と 左上 に 3 つ の button が 出る:

  • パッケージ化 されて いない 拡張機能 を 読み込む ← これ を click
  • パッケージ化
  • 更新

ファイル 選択 ダイアログ が 開く → 手順 2 で 展開 した FP-Compass-拡張機能 フォルダ を 選択 → 「開く」。

5拡張 が 一覧 に 出れば OK

拡張機能 の カード が 出て、 version が 1.3.0 なら 完了。

Chrome 右上 の 拡張 アイコン (🧩) を click → FP Compass 拡張 を 「pin」 (画鋲マーク) で 固定 して おく と 便利。

SECTION 03 使い方 (通常 flow)

install 済 なら、 FP Compass で 「Zoom 面談」 button を 押す だけ。 拡張 が 全部 自動で やる。

1FP Compass に ログイン

Chrome で https://app.skeleton-inc.jp/ を 開いて ログイン。

2顧客カルテ で 「Zoom 面談」 button を click

顧客リスト → 該当 顧客 の カード click → 「Zoom 面談 開始」 button (or 「急遽 Zoom」) を click。

3拡張 が 自動 で 動く

ここ から は 拡張 が 全部 自動 で やる。 owner の 追加 click は 不要。

  • 拡張 が client 情報 で arm される (Chrome 右上 の 拡張 アイコン に 緑 の ▶ badge)
  • 新しい Zoom タブ が 自動 で 開く
  • Zoom タブ の 読み込み 完了 → 自動 で 録音開始 (badge が 赤 REC に 変わる)
4Zoom で 面談 (AirPods OK)

普通 に Zoom で 面談 する。 AirPods 使用中 でも 相手 の 声 も owner の 声 も 両方 録音 される。

  • 相手 の 声: Zoom タブ の 音声 を 拡張 が tabCapture で 拾う
  • owner の 声: マイク (AirPods) を getUserMedia で 拾う
  • 両方 を 合成 → 1 本 の 音声 に 収録
5面談 終了 → Zoom タブ 閉じる

Zoom タブ を 閉じる だけ。 拡張 が 検知 → 自動 stop → 音声 blob を FP Compass に 送信 → Whisper で 文字起こし → Claude で 5 section 議事録 生成 → 顧客カルテ の 議事録タブ に 表示 (5〜10分)。

ℹ 停止 button 押す 必要 なし: Zoom タブ を 閉じた 瞬間 に 自動 stop + 送信 まで やる。
SECTION 04 うまく 行かない 時

Chrome の 安全機能 で 「User gesture 制約」 が 効いて 自動 開始 に 失敗 する 事 が ある。 その時 は 拡張 アイコン を 1回 click で 起動 する。

▲「自動録音 失敗」 の toast が 出た 時

FP Compass 下部 に オレンジ の toast:

⚠ 自動録音 失敗: 山口様 — Chrome 右上 の 拡張アイコン ( ▶ 表示) を 1回 クリック で 録音開始

この場合 は Zoom タブ に 切り替え て → Chrome 右上 の 拡張 アイコン (▶ 緑 badge) を 1回 click → 録音開始。 (完全 自動 の 半歩手前)

?拡張機能 が 認識されない (window.__fpTabRecorder 未定義)

症状: FP Compass で Zoom button 押しても 「拡張入ってる」 認識が 出ない。

原因: v1.1.0 以前 (CSP bug)、 or 拡張 が disabled。

対処:

  • chrome://extensions/ で FP Compass 拡張 が v1.3.0 か 確認
  • 拡張 switch が ON か 確認
  • FP Compass タブ を Cmd+Shift+R で ハードリロード
  • DevTools (F12) console で window.__fpTabRecorder と 打って "1.3.0" が 返る か 確認
🎙マイク 音声 が 入らない (owner の 声 が 録音されない)

原因: Chrome の マイク 権限 が offscreen document に 与えられて いない。

対処:

  • Mac の システム設定 → プライバシー と セキュリティ → マイク で Chrome が ON か 確認
  • Chrome の URL バー 左 の 🔒 アイコン → 「サイト の 設定」 → マイク が 「許可」 か 確認
  • AirPods を 使う 場合 は Mac の 「サウンド → 入力」 で AirPods が 選択 されて いる か 確認
📹Zoom タブ が 開いても 録音 始まらない

原因: Zoom タブ の 読み込み が 遅れて 拡張 が timing miss。

対処: Chrome 右上 の 拡張 アイコン (▶ 緑) を 1回 click → 手動で 録音開始。 (「うまく 行かない 時 の toast」 と 同じ 対処)

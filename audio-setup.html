A. Chrome 拡張 install 手順

FP Compass 事務局 に 連絡 頂ければ、 Chrome拡張 ファイル を お送りします (Chrome Web Store 公開 準備 中)。

1拡張 ファイル を 受け取る

下記 の いずれか から 入手:

  • FP Compass アプリ 内 「アカウント」 → 「音声設定」 → 「Chrome拡張 を DL」 ボタン
  • Skeleton Inc. サポート に メール で 依頼 → support@skeleton-inc.jp

2Chrome の 拡張機能 画面 を 開く

Chrome の アドレスバー に chrome://extensions/ と 入力 → Enter

3デベロッパー モード を ON

右上 の 「デベロッパー モード」 スイッチ を ON に する

4拡張 を 読み込む

「パッケージ 化 されて いない 拡張機能 を 読み込む」 ボタン → 受け取った フォルダ を 選択

拡張 リスト に 「FP Compass 議事録レコーダー」 が 追加 されれば OK

5使い方

  1. Zoom Web版 (zoom.us) を タブ で 開いて 面談 開始
  2. Chrome 右上 の 拡張 アイコン クリック → 「Zoom タブ 録音 を 開始」
  3. Chrome の 共有 ダイアログ で 該当 Zoom タブ を 選択
  4. 面談 終了 → 拡張 popup で 「録音 を 停止」
  5. FP Compass に 音声 が 自動 送信 → Whisper で 議事録 生成

B. BlackHole 手順 (所要 5 分)

1BlackHole を インストール

ターミナル.app で 以下 を コピペ 実行 (Homebrew 未導入 なら 事前に brew.sh):

brew install --cask blackhole-2ch

パスワード 入力 プロンプト が 出たら Mac の 起動 パスワード。

2Audio MIDI 設定 で 「Multi-Output Device」 作成 (相手の声 を Bluetooth と BlackHole に 同時 出力)

  • Spotlight (⌘+Space) で Audio MIDI と 入力 → 「Audio MIDI 設定」 を 開く
  • 左下 の + ボタン → 「Multi-Output Device を 作成」
  • 右側 で AirPods (or 使用中の Bluetooth ヘッドホン) と BlackHole 2ch の 両方 に チェック
  • 左側 リスト の この 新しい 機器 を 右クリック → 名前 を FP Compass 出力 に 変更

3「機器セット」 を 作成 (自分の声 + 相手の声 を 合成)

  • Audio MIDI 設定 の + → 「機器セット を 作成」
  • 右側 で 内蔵マイク と BlackHole 2ch の 両方 に チェック
  • 名前 を FP Compass 入力 に 変更

4Zoom の スピーカー を 切替

  • Zoom → 設定 → オーディオ
  • スピーカー を FP Compass 出力 に 変更
  • マイク は そのまま (内蔵マイク or AirPods マイク)

これで Bluetooth ヘッドホン から 相手の声 が 聞こえつつ、 BlackHole にも 同じ 音 が 流れる。

5FP Compass で マイク を 切替

  • FP Compass で 議事録録音 開始 時 の マイク 選択 で FP Compass 入力 を 選ぶ
  • Chrome の 「マイク の 使用 許可」 は 初回 のみ

以降、 議事録録音 は 自動で 「自分 + 相手」 の 両声 を 拾う。

FAQ

Q: 有線 ヘッドホン なら 設定 不要?
A: 有線 の 場合、 PC の スピーカー から も 相手 の 音 が 漏れる ので、 内蔵マイク が それ を 拾い、 録音 できる ことが 多い。 ただし 環境 によって 不安定 なので、 上記 設定 を 推奨。
Q: 対面 面談 (Zoom なし) の 録音 も 影響 する?
A: しない。 対面 の 場合 は 内蔵マイク (or 外付けマイク) が 両者 の 声 を 拾う。 上記 設定 は Zoom 時 のみ 有効。
Q: Windows でも 同じ 手順?
A: 違う。 Windows は VB-CABLE という 類似 ツール で 同等 の 設定 が 可能。 別ガイド 準備中。
Q: 設定 が うまく いか ない
A: jobs@skeleton-inc.jp まで 連絡 (画面録画 添付 だと 早い)。

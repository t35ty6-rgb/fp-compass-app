プライバシーポリシー

スケルトン株式会社 (以下 「当社」) は、 顧客向け iOS アプリ 「FP コンパス」 (以下 「本アプリ」) の 利用者様 (以下 「お客様」) の 個人情報 を 適切 に 取り扱う ため、 本プライバシーポリシー を 定めます。

01対象範囲

本ポリシー は、 本アプリ を 通じて 当社 が 取得・利用する 個人情報 に 適用 されます。 本アプリ を 使用 する 際 に お客様 が 契約 している ファイナンシャルプランナー (以下 「担当 FP」) が 別途 定める プライバシー方針 と は 独立 して 適用 されます。

02取得する情報

本アプリ の 利用 に あたり 以下 の 情報 を 取得 します。

認証情報

  • Apple ID 経由 で 提供 される 匿名化 ユーザー ID
  • お客様 が 明示的 に 共有 を 許可 した メールアドレス と 表示名

担当 FP との 紐付情報

  • 担当 FP から 発行 された 招待コード
  • 紐付 後 の テナント ID · 顧客 ID

面談 準備 情報 (事前 質問 の 回答)

  • 年代 · 職業 · 家族構成 · 世帯年収 · 住居形態
  • 金融資産 の 概算 · 保有 商品 の 種類
  • 相談したい テーマ · 具体的 な 悩み · 理想 · 緊急度
  • 生年月日 · 面談 希望 時間帯

面談 記録

  • 担当 FP と の 予約日時 · Zoom URL
  • 面談 後 の 議事録 (担当 FP が 作成 · 更新)

技術情報

  • プッシュ通知 用 の 端末トークン (Expo Push / APNs)
  • OS · アプリ バージョン · 端末 種別 (障害 対応 の ため)
  • アプリ 内 で 発生 した エラー ログ
本アプリ は クレジットカード 番号 · 銀行口座 番号 · マイナンバー を 取得 しません。 担当 FP から 別途 これら の 提出 を 求められる 場合 が ありますが、 本アプリ の 経路 は 使用 しないでください。

03使用目的

  • 担当 FP と お客様 の 面談 準備 · 予約 調整 · 議事録 共有
  • お客様 の 資産設計 相談 に 資する 情報 の 蓄積 · 参照
  • プッシュ通知 に よる 面談 連絡 · リマインド 送信
  • 不正利用 の 検知 · 防止
  • お問い合わせ 対応
  • 本アプリ の 品質 改善 · 障害 対応

04第三者への提供

当社 は、 お客様 の 個人情報 を 以下 の 場合 を 除き 第三者 に 提供 しません。

  • お客様 の 招待コード を 発行 した 担当 FP (お客様 の 明示的 な 紐付 操作 に よる 提供)
  • 法令 に 基づく 開示 請求 が あった 場合
  • 人 の 生命 · 身体 · 財産 の 保護 の ため 必要 が あり、 かつ 本人 の 同意 を 得る こと が 困難 な 場合

業務委託

当社 は 以下 の 業務委託先 に 個人情報 の 処理 を 委託 して います。 委託先 に は 個人情報 保護 に 関する 契約 を 締結 し、 適切 な 管理 を 求めて います。

Google LLC (Firebase Authentication · Cloud Firestore · Cloud Functions · Cloud Storage)
認証 · データ 保管 · サーバー 処理 の インフラ 提供。 データ 保管 は 東京 リージョン。
Apple Inc. (Sign in with Apple · APNs Push Notification Service)
認証 プロバイダー · プッシュ通知 の 配信。
Expo Application Services, Inc. (Expo Push Notifications)
プッシュ通知 の トークン 中継。
Zoom Video Communications, Inc.
面談 の 動画 通信 · 録画 (担当 FP の 選択 に よる)。

05保管期間 と 削除

当社 は 以下 の 期間、 お客様 の 個人情報 を 保管 します。

  • 認証情報 · 面談 記録: お客様 が 担当 FP と の 契約 を 継続 して いる 間
  • プッシュ通知 トークン: サインアウト または 端末 変更 まで
  • エラー ログ · 技術情報: 取得 から 90 日

お客様 が サインアウト された 場合、 プッシュ通知 トークン は 即時 に 削除 されます。 アカウント の 完全 削除 を ご 希望 の 場合 は、 担当 FP または 下記 お問い合わせ先 まで ご連絡 ください。 ご連絡 から 30 日 以内 に 該当 データ を 削除 します。

06お客様の権利

お客様 は 以下 の 権利 を 有します。

  • 当社 が 保有 する ご 自身 の 個人情報 の 開示 を 求める 権利
  • 内容 に 誤り が ある 場合 の 訂正 · 追加 · 削除 を 求める 権利
  • 利用停止 · 消去 · 第三者 提供 停止 を 求める 権利

これら の 権利 行使 の ご請求 は、 下記 お問い合わせ先 まで ご連絡 ください。 ご本人確認 の 上 で 対応 いたします。

07セキュリティ

  • すべて の 通信 は TLS 暗号化 に よる HTTPS で 保護 されます。
  • データ は Google Cloud Firestore の 東京 リージョン に 保管 され、 保存時 暗号化 (AES-256) が 適用 されます。
  • お客様 の 個人情報 は、 ご 自身 と 担当 FP の みが 参照 できる よう Firestore セキュリティルール で 制御 されて います。
  • 資産情報 の 閲覧 は Face ID / Touch ID による 生体認証 で 保護 されます。

08Cookie · 端末識別子

本アプリ は 広告 目的 の Cookie · 端末識別子 を 使用 しません。 プッシュ通知 に 必要 な 端末 トークン のみ を 取得 します。

09改定

当社 は 法令 の 変更 · サービス の 変更 に 伴い、 本 プライバシーポリシー を 改定 する こと が あります。 重要 な 変更 が あった 場合 は、 本アプリ 内 の 通知 または メール で お知らせ します。
